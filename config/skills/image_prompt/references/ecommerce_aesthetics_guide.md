# 电商图片设计三维体系：构图·美学·中文排版

本指南是所有电商生图 Skill 的底层美学教科书，定义了专业电商视觉的三大支柱。

---

## 第一维：6 大黄金构图模式（骨骼）

电商图必须为文案预留**绝对干净的文字安全留白区（Negative Space）**。

### 1. `rule_of_thirds_negative_space` — 三分留白构图
- **空间分配**：核心商品置于左下或右下 1/3 视觉交点（占 50%~60%），**对角侧预留 30%~40% 纯净留白区**（柔焦虚化背景或纯色肌理）。
- **镜头**：平视或微俯 15°~25°，50mm~85mm 标准镜头，主体 100% 锐利，背景奶油般化开。
- **适用**：主图首图、详情页首屏、礼盒主推图。
- **实战**：莓茶礼盒居右下，左上云海留白排《满披白霜·高山芽尖》，绝不遮挡包装。

### 2. `extreme_macro_texture` — 光学微距局部满画幅
- **空间分配**：85mm 或 100mm f/2.8 微距镜头贴近拍摄，核心质地占 65%~75%，极浅景深在**顶部或一角化开 25%~30% 柔焦留白区**。
- **光线**：硬朗侧逆光 30° 角掠过表面，微观结晶/绒毛/油脂光泽纤毫毕现。
- **适用**：主图第 2 张（视觉锤）、原料特写屏、成分质地屏。
- **实战**：黑粗陶茶则上莓茶嫩芽放大至根根分明，银白霜层在侧逆光下闪烁，右上深色虚化区印米白宋刻体。

### 3. `depth_layering` — 前中远三层景深构图
- **空间分配**：**前景（10%~15%）**局部切入微虚化道具 + **中景（50%）**核心商品 100% 锐利 + **远景（35%）**大光圈虚化环境氛围（顶部或侧上方保留 30% 干净留白）。
- **适用**：多图融合（`multi_image_fusion`）、体验图、冲泡/喂食场景。
- **实战**：前景透亮玻璃杯莓茶汤，中景包装罐字迹清晰，远景木窗晨光山林，顶部留白排核心卖点。

### 4. `diagonal_dynamic_flow` — 对角线流体动态构图
- **空间分配**：核心引导线沿 45° 对角线（左上至右下或右上至左下）贯穿，展现瞬时物理动态（1/2000s 高速快门），**对角另一侧三角区预留 30% 留白**。
- **动态元素**：沸水高冲激起翻滚茶汤、手指捻茶洒落霜末、营养颗粒倾倒动态瞬间。
- **适用**：冲泡/饮用体验图、痛点解决瞬间、短视频首帧。

### 5. `split_screen_comparison` — 黄金比例分屏对比构图
- **空间分配**：垂直或斜切分割为左右（或上下）对比视窗——**70% 我方好产品（主视窗）vs 30% 普通对照品**，或 50%:50% 对称对比；**顶部预留 20% 通栏标题区**。
- **光影反差**：我方产品视窗温暖通透商业棚拍光 + 高锐度微距；对照视窗低饱和度冷灰自然光客观呈现（严禁恶意丑化）。
- **适用**：详情页"选购小知识"客观对比屏、差异化卖点图。

### 6. `knolling_flat_lay` — 90° 垂直俯拍秩序美学
- **空间分配**：相机 90° 正上方俯拍，商品外包装、独立内袋、干茶样品、冲泡茶杯、**CMA 检测报告原件**按平行或直角几何网格秩序陈列；**上方或正中央预留 25%~30% 干净桌面留白区**。
- **光影**：大面积柔和顶光 + 轻微侧向漫反射，报告纸面无反光、包装边缘有真实微小接触阴影。
- **适用**：主图第 5 张（权威检测背书/规格全家福）、参数规格屏、品质定心丸屏。

## 第二维：5 大设计美学流派（皮肤）

同一商品套上不同美学皮肤，击中的消费心理与客单价截然不同。

### 1. 🍵 `new_chinese_zen` — 新中式茶席禅意美学
- **意境**：宋代极简、东方书卷气、幽暗明暗对比（Chiaroscuro）、山野禅意留白。
- **道具库**：手工粗陶茶则、深色老竹木茶盘、自然宣纸、斑驳青苔原石、锤纹玻璃公道杯（单图 ≤3 件）。
- **标准色板（HEX）**：
  - 背景主色：深苍山绿 `#1B3328`、宋韵暖炭黑 `#1E1E1C`
  - 辅助留白：古法宣纸米白 `#F5F2EB`、远山青灰 `#8A9A86`
  - 点睛高光：透亮琥珀茶汤金 `#D4AF37`、印章朱砂红 `#B83B2A`
- **光线**：清晨 45° 侧逆光穿透山间薄雾，柔和丁达尔光束（Tyndall effect）+ 温润木质漫反射。
- **最佳匹配**：张家界莓茶（特级芽尖、高端礼盒、淘宝/微信小店送长辈与商务客群）。

### 2. 🌿 `organic_nature_sunlight` — 原生态山野呼吸感美学
- **意境**：原产地清晨真实阳光、鲜活晨露感、高通透自然光、无修图般自然生机与纯净源头感。
- **道具库**：张家界武陵源石英砂岩肌理、清晨带露珠鲜嫩茶树枝叶、原木桌面、清澈山泉水波纹。
- **标准色板（HEX）**：
  - 背景主色：云海晨雾白 `#F4F7F4`、鲜活嫩芽绿 `#4A7C59`
  - 辅助留白：石英砂岩暖灰 `#D8D2C5`、山林远景青 `#2C4A3E`
  - 点睛高光：明黄微绿茶汤色 `#E5C158`、银白结晶霜色 `#FFFFFF`
- **光线**：5500K 清晨通透自然日光，高动态范围（HDR），背景山峰云海大光圈柔焦虚化。
- **最佳匹配**：张家界莓茶（日常口粮茶、产区溯源屏、强调高山源头直发与天然无污染）。

### 3. 🔬 `clinical_lab_minimal` — 科学实证与临床极简美学
- **意境**：瑞士实验室级严谨、高调纯净无影棚拍、光学仪器般精确感、数据可视化权威信任感。
- **道具库**：哑光亚克力展台、高硼硅光学玻璃器皿、金属精密量勺、严谨 CMA 检测报告原件。
- **标准色板（HEX）**：
  - 背景主色：实验室冰川白 `#F8FAFC`、极简科技浅灰 `#E2E8F0`
  - 辅助边框：精密银灰 `#94A3B8`、深海权威蓝 `#0F172A`
  - 点睛高光：科学活力蓝 `#0284C7`、安全草本绿 `#16A34A`
- **光线**：高调无影柔光箱（High-key Studio Softbox），边缘轮廓极其锐利，零杂乱阴影。
- **最佳匹配**：宠物营养补充剂（全系列主推风格）、张家界莓茶"植物黄酮检测报告背书屏"。

### 4. 🏡 `nordic_warm_lifestyle` — 北欧暖阳治愈生活美学
- **意境**：午后四点钟阳光百叶窗光影、温馨松弛居家/办公氛围、人宠亲密陪伴温度。
- **道具库**：奶油色原木餐桌/办公桌、天然粗亚麻桌布、莫兰迪色陶瓷碗/马克杯、阳光绿植光影。
- **标准色板（HEX）**：
  - 背景主色：暖阳奶油米白 `#FAF6F0`、燕麦亚麻色 `#E6DEC8`
  - 辅助字体：深烘焙咖啡棕 `#3E2F23`、柔和鼠尾草绿 `#7D8C75`
  - 点睛高光：暖阳琥珀橙 `#E08E45`
- **光线**：4000K 温暖斜射午后阳光，桌面投射柔和窗棂光影（Window Gobo Shadows）。
- **最佳匹配**：宠物营养品日常喂食互动图、莓茶办公室下午茶/饭后解腻生活场景图（微信小店极高转化）。

### 5. 💥 `high_impact_retail` — 高对比零售视觉锤美学
- **意境**：一秒抓眼球强视觉冲击、高饱和色彩碰撞、商品份量感溢出屏幕、利益点直给零废话。
- **道具库**：高质感纯色立体展台、直接堆叠展示饱满实物内料（满霜干茶/大把营养片）、醒目价格/规格角标容器。
- **标准色板（HEX）**：
  - 背景主色：浓郁翡翠深绿 `#0D3B2E` 或 喜庆赤金红 `#8B1E1E`
  - 文字高亮：高反差明黄 `#FFD700`、纯白 `#FFFFFF`
- **光线**：硬朗商业闪光灯 + 强力轮廓分离光（Strong Rim Light），把商品主体像 3D 浮雕一样从背景中"抠"出来。
- **最佳匹配**：拼多多搜索首图、大促活动图、多罐装规格全家福。

## 第三维：中文排版体系（灵魂）

汉字是笔画密集方块字。要让 AI 排出高级感且 95%+ 零乱码准确率的中文，必须执行 **4 大排版铁律**。

### 铁律 1：美学流派与中文字体气质的强制绑定

严禁所有图都用默认黑体！不同美学必须绑定对应字体风格：

| 美学流派 | 绑定中文字体 | 英文描述（供生图 Skill 调用） |
|---|---|---|
| 🍵 新中式茶席禅意<br>🌿 原生态山野呼吸 | **东方人文宋刻衬线体**<br>*(加朱红小印章点缀)* | `elegant high-contrast Chinese Songti (Ming serif) typography with refined sharp strokes and generous letter-spacing, accented by a small traditional vermilion red seal stamp` |
| 🔬 科学实证极简风<br>💥 高对比零售视觉锤 | **现代粗黑无衬线体**<br>*(Swiss Grid Sans-Serif)* | `bold modern geometric Chinese Heiti (sans-serif) typography with heavy uniform stroke weight and clean Swiss-grid alignment` |
| 🏡 北欧暖阳治愈风 | **亲和圆黑体 / 柔黑体** | `warm rounded modern Chinese sans-serif typography with soft approachable edges` |

### 铁律 2：三级视觉层级法则（3 : 1.2 : 0.8 黄金字号比）

电商海报文字必须拆分为主次分明的三层：

1. **一级视觉锤（主标题 `Headline` — 权重 3.0）**：
   - 字号最大、字重最粗（Bold / Heavy），字数严格 **4~10 个汉字**。
   - 直接放置在构图预留的干净留白区视觉中心，确保手机缩略图 1 秒可读。

2. **二级解释层（副标题 `Subheadline` — 权重 1.2）**：
   - 字号缩小为主标题 **40% 左右**，中等字重（Medium / Regular），紧贴主标题下方或侧方对齐，字数 **8~16 个汉字**，可用极细装饰线或间隔号 `·` 分隔。

3. **三级信任胶囊/角标（`Pill Badge / Seal Tag` — 权重 0.8）**：
   - 凡是 **2~6 个字**的短卖点或背书词（如 `CMA权威检测`、`头采嫩芽`、`张家界核心产区`），**必须装进"圆角胶囊框（sleek rounded pill-shaped badge）"或"中式边框/印章容器"内**！防止散碎小字凌乱，瞬间拉满精致度。

### 铁律 3：横排 vs 古典竖排版式法则

- **现代横排（Horizontal Layout）**：适用于**拼多多全系图、宠物营养补充剂全系图、包含阿拉伯数字/百分比的科学实证图**，阅读效率最高。

- **新中式古典竖排（Vertical Chinese Typography）**：**张家界莓茶专属高级感杀手锏！** 当采用 `三分留白构图` 且美学为 `新中式茶席禅意` 或 `原生态山野` 时，将莓茶包装与茶汤置于画面左下方，在**右上方干净云雾或深绿留白区采用 1~2 列竖排宋刻体**（旁缀一枚小朱砂红印章），瞬间呈现千元级东方茗茶大牌海报气场。

### 铁律 4：明暗高反差与 AI 中文防乱码铁律

1. **明暗反差防吞字（强制配色绑定）**：
   - **深色留白底**（深苍山绿 `#1B3328` / 暖炭黑 `#1E1E1C`） → 强制配 **宣纸米白字 (`#F5F2EB`)** 或 **香槟烫雅金字 (`#D4AF37`)**。
   - **浅色留白底**（云海白 `#F4F7F4` / 奶油米白 `#FAF6F0` / 冰川白 `#F8FAFC`） → 强制配 **深墨绿字 (`#1B3328`)** 或 **浓炭黑字 (`#222222`)**。

2. **严禁跨纹理与零遮挡铁律**：
   - 所有排版文字必须 **100% 落在预设干净留白区**（纯色底或大光圈柔焦虚化区域）内；**绝对禁止**文字横跨复杂树枝交界处、干茶颗粒上，**绝对禁止**遮挡商品包装本体。

3. **"少字大号 + 双引号逐字锁死"防乱码法则**：
   - 单张图片上由 AI 额外渲染的海报汉字总数严格控制在 **18 个汉字以内**（主图建议 ≤14 字）。字数越精炼、字号越大，AI 分配给每个汉字笔画的像素网格越充裕，笔画越锋利零错字。
   - 在编译英文生图提示词时，所有需要渲染的中文文本必须使用英文双引号 `""` 逐字包裹锁死（例如：`Render the exact Chinese headline "满披白霜·高山芽尖"`），并与商品包装上原有印刷字严格区分（包装原有文字保持 100% 像素级冻结不重绘）。

## 第四部分：槽位场景与三维自动映射总表

当用户选择 `auto（AI 自动匹配）` 时，系统策划引擎与生图设计师按以下黄金矩阵自动匹配最优三维组合：

| 槽位场景类型 | 自动匹配【构图模式】 | 自动匹配【设计美学】 | 自动匹配【中文排版方案】 |
|---|---|---|---|
| **莓茶·主图第1张/首屏海报**<br>*(淘宝/微信小店)* | `rule_of_thirds_negative_space`<br>*(主体居右下，左上 35% 留白)* | `new_chinese_zen` 或 `organic_nature_sunlight` | 东方宋刻体·竖排或左对齐 3:1 层级 + 朱红小印章 |
| **莓茶·主图第1张**<br>*(拼多多高点击)* | `rule_of_thirds_negative_space`<br>*(包装+满霜干茶双主体)* | `high_impact_retail` | 超大号现代粗黑体·顶部横排撞色大字 + 利益点胶囊标 |
| **莓茶·白霜视觉锤微距**<br>*(主图第2张/白霜屏)* | `extreme_macro_texture`<br>*(100mm 光学微距 + 侧逆光)* | `new_chinese_zen`<br>*(深色粗陶茶则衬托银白霜)* | 暗部留白区配米白/雅金宋刻体主标题 + `[天然黄酮结晶]` 胶囊标 |
| **莓茶·金黄茶汤与回甘体验**<br>*(主图第3张/冲泡屏)* | `depth_layering` 或 `diagonal_dynamic_flow` | `organic_nature_sunlight` 或 `nordic_warm_lifestyle` | 浅色通透留白区配深墨绿宋刻体，传达"入口微苦·三秒回甘" |
| **莓茶/宠物品·选购客观对比屏** | `split_screen_comparison`<br>*(70% 暖光好品 vs 30% 冷光普通品)* | `clinical_lab_minimal` | 顶部通栏横排现代粗黑对比标题 + 左右两侧圆角胶囊特征标签 |
| **莓茶/宠物品·权威检测与规格屏**<br>*(主图第5张/证据屏)* | `knolling_flat_lay`<br>*(90° 俯拍包装+报告秩序平铺)* | `clinical_lab_minimal` 或 `nordic_warm_lifestyle` | 顶部干净留白区排现代粗黑体标题 + 实测数据圆角胶囊角标 |
| **宠物补充剂·科学配方/主图** | `rule_of_thirds_negative_space` 或 `extreme_macro_texture` | `clinical_lab_minimal` | 瑞士网格现代粗黑无衬线体 + 科技银蓝圆角数据胶囊框 |
| **宠物补充剂·喂食互动场景** | `depth_layering` | `nordic_warm_lifestyle` | 亲和圆黑体·暖白/深棕高反差横排 + 适口性卖点胶囊标 |
