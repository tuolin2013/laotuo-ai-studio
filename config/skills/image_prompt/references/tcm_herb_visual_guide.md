# 本草性状生图指南：让每一味草本原料都画得像真的

> 外观依据：《中国药典》2020 年版一部各品种的【性状】与饮片【性状】，片、段、块、丝的规格依据药典四部通则 0213。
> 本指南只讲**外观**（形状、尺寸、颜色、断面、质地），不涉及任何原料的作用。生图提示词与上图文字同样只写外观和原料名。

指令末尾的《原料性状图谱》会列出本槽位画面提到的每味原料，含中文性状要点和可直接使用的英文外观描述（`prompt_en`）。图谱是事实依据，写提示词时**逐味照抄**，不要自己发挥。

## 一、六条铁律

1. **画干燥饮片，不画鲜植物。** 原料是药房里的干燥切片、切段或整粒干果，不是田里的鲜花、绿叶、鲜果。英文必须写 `dried`。
2. **只画图谱里列出的原料，最多 4 味。** 不得为了好看加别的叶子、花朵、香料、坚果。图谱末尾标明「本图不画实物」的原料，只能出现在中文文案里。
3. **每味单独一小堆。** 每味原料放在各自的白瓷小碟、竹编小簸箕或一小堆里，堆与堆之间留空隙，绝不混成一堆杂片。
4. **尺寸按真实比例。** 用包装盒做比例尺：盒子 154×80×20mm，片剂 0.4g 一片。5mm 的种子约为盒子高度的 1/30，车前子、菟丝子只有 1~2mm，像细沙。不要把小籽画成豆子大小。
5. **画出区分特征。** 每味原料至少写出 1 个一眼可辨的特征（见「二、外形相近的六组」），同组原料同框时必须写出彼此的区别。
6. **合规。** 不画药铺、药柜、药方、药瓶、注射器、听诊器、病历等医疗感元素；原料旁不加图标、箭头或人体部位示意。道具用白瓷小碟、竹编簸箕、原木托盘、亚麻布。

## 二、外形相近的六组，靠这些特征区分

### A. 根和根茎切片（最容易画成同一种「黄白圆片」）

| 原料 | 一眼可辨的特征 |
|---|---|
| 甘草 | 红棕色薄外皮，黄白切面上有细放射纹和一圈环 |
| 党参 | 带灰黄皱皮，切面淡黄，有裂隙和放射纹，略有韧性 |
| 桔梗 | 去皮后白净，切面一圈棕色细环，裂隙多 |
| 赤芍 | 棕褐粗皮，切面粉白至粉红，放射纹清晰 |
| 泽泻 | 淡黄外圈，切面粉性，布满细孔 |
| 土茯苓 | 大而薄的不规则片，粉性切面带小亮点 |
| 白术 | 大片，切面黄白，油点稀疏、棕黄色 |
| 苍术 | 切面油点密集、橙红色，有的起白霜 |
| 木香 | 切面中部有菊花心状放射纹，散有褐色油点 |
| 川芎 | 片的轮廓起伏像蝴蝶翅膀，切面有波状环纹 |
| 知母 | 小片，边缘带黄棕色毛须 |
| 金荞麦 | 质硬，切面淡棕红，中心颜色较深 |
| 黄精 | 半透明角质样切面带筋脉小点；酒制黄精乌黑油亮 |
| 姜黄 | 金黄至橙棕色，蜡样光泽，有一圈环纹 |
| 升麻 | 黑褐色外缘，黄绿色切面有网纹，体轻 |
| 葛根 | 纤维感很强的浅黄棕小方块 |
| 茯苓 | 纯白、颗粒感、没有任何纹理的方块 |

### B. 小籽粒

补骨脂是黑色哑光的扁肾形（3~5mm）。酸枣仁是紫红色、有光泽的扁圆粒（5~9mm），一面中央有一条纵线。车前子是约 2mm 的扁椭圆粒。菟丝子是 1~2mm 的灰棕色哑光圆粒。薏苡仁是乳白色的宽卵形粒（4~8mm），一侧有一条深纵沟。

### C. 果实

| 原料 | 外观 |
|---|---|
| 枸杞子 | 红色纺锤形，底端一个白点 |
| 沙棘 | 橙黄至棕红的皱缩小球，常几个粘成一团 |
| 山茱萸 | 紫红色的破囊状果肉，有光泽，没有核 |
| 女贞子 | 黑紫色皱缩的卵形小粒，可带白霜 |
| 桑椹 | 长圆形聚合果，表面颗粒感明显，带短梗 |
| 诃子 | 2~4cm 的棕色卵形干果，有 5~6 条纵棱 |
| 榧子 | 橄榄形，灰黄色薄硬壳，不是深色的炒货 |

### D. 树皮与根皮

杜仲掰开时会拉出银白色胶丝，内表面暗紫色，这是它独有的标志。厚朴外面灰褐、里面紫棕，看起来油润，常卷成筒状。地骨皮是薄卷筒，外皮呈鳞片状剥落，内面黄白色。

### E. 藤茎与细根段

| 原料 | 外观 |
|---|---|
| 夜交藤（首乌藤） | 紫红色皮环，包着多孔的黄白色木部，中心有白髓 |
| 茜草 | 很细（2~10mm），红棕至紫红，切面多孔 |
| 桑枝 | 灰黄色薄皮，黄白木部有放射线，中心一点小白髓 |
| 远志 | 带深横纹的细**空心**管 |

### F. 草类切段、花、叶、鳞茎

| 原料 | 外观 |
|---|---|
| 益母草 | 方茎段，切面中间是**实心**白髓 |
| 泽兰 | 方茎段，节是紫色的，有白毛，中间**空心** |
| 鱼腥草 | 红棕色带棱的扁茎段，夹着心形碎叶 |
| 蒲公英 | 根段、羽状裂叶碎片和带白色冠毛的种子混在一起 |
| 金银花 | **闭合**的细棒状花蕾，长 2~3cm，黄白色带绒毛 |
| 野菊花 | 黄豆大小（3~10mm）的黄色小花球 |
| 银杏叶 | 干燥的扇形叶，黄绿或浅棕黄，叶脉从叶柄呈扇状分出，没有中脉 |
| 薤白 | 半透明蜡质的小鳞茎，有白色膜皮，像缩小的干葱头 |

## 三、AI 常见画错

- 金银花画成开放的花朵。应为闭合花蕾。
- 银杏叶画成鲜绿色或秋天的金黄色。应为干燥后的黄绿或浅棕黄。
- 沙棘、枸杞子画成饱满发亮的鲜果。应为皱缩的干果。
- 野菊花画成大朵菊花或贡菊。实际只有黄豆大小。
- 山茱萸画成完整的圆果。饮片是去了核的破囊状果肉。
- 远志画成实心段。应为空心管。
- 升麻照着北美的 black cohosh 画。本品是中药升麻的根茎片。
- 榧子画成深褐色的炒香榧零食。
- 车前子、菟丝子画成豆子大小，尺寸失真。
- 所有根片画成一样的黄白圆片。要按「二」中 A 组写出每味的切面特征。
- 几味原料混成一堆，分不清谁是谁。

## 四、提示词写法

**英文提示词（GPT-Image）**：在主体描述之后插入原料段落：

`In the foreground, exactly N separate small piles of dried herbal ingredients on small white porcelain dishes, botanically accurate pharmacy-grade dried slices, true to real scale next to the 154 mm box: Pile 1: <图谱 prompt_en 原文>. Pile 2: …`

**中文叙述（Nano-Banana）**：用一句话说明「前景 N 个白瓷小碟，每碟一味干燥饮片，按真实比例」，再逐碟引用图谱英文描述。

**避免项**（写入 `negative_notes`）：`fresh plants, open flowers, mixed herb pile, invented or extra herbs, wrong scale, identical-looking slices`。

## 五、有原料实拍参考图时

如果本次传入了角色为 `herb_ingredients` 的参考图（用户拍的原料实物），它比文字描述更可靠，必须优先使用：

- GPT-Image 写法：`Image N is a real photo of the herbal ingredients: reproduce each herb's shape, color, cut face and size exactly as in the photo; you may arrange them into separate small piles.`
- Nano-Banana 写法：`the Nth image (real herbal ingredients)`。说明照着这张照片还原每味原料的形状、颜色、切面和大小，可以重新摆成分开的小堆。
- 照片里没有的原料，仍按图谱的文字描述绘制。
