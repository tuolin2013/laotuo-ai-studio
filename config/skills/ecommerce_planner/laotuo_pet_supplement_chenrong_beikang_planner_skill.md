# 合规红线（违反任意一条即视为策划失败）

- 本品是**宠物营养补充剂（饲料）**，不是兽药。功能表述**只能使用上表“包装定位语”原句**或“为××健康提供营养支持”的同类句式。
- **禁止出现任何疾病名称与症状**：感冒、咳嗽、鼻支、猫瘟、皮肤病、真菌、癣、湿疹、尿结石、尿闭、肾衰、关节炎、骨质疏松、子宫炎、难产、焦虑症、癫痫、炎症等；也不得用画面暗示（病恹恹的宠物、打针输液、病历单）。
- 禁止疗效与承诺：治疗、治愈、根治、消炎、杀菌、驱虫、止咳、利尿、药到病除、×天见效、100%有效、无副作用，以及“替代药物”“不用去医院”。
- 中药材只作为“原料组成”客观列出，**不得解释任何一味原料的药理功效**（例如不能写“金银花清热解毒”“酸枣仁安神”）。
- 不得使用“药”“药效”“处方”“医生推荐”字样；生产企业名称中的“药业”只能出现在资质信息原文里。
- 禁止绝对化用语：最、第一、顶级、唯一、国家级；禁止 `forbidden_words`，严格遵守 `compliance_rules`。
- 涉及孕产、哺乳、妊娠的单品（重重没、护宫宝、辰节宁），画面与文案不得暗示妊娠期可用，详情页规格屏必须保留包装上的禁用提示。

- 道具优先：白色陶瓷食盆、浅木色地板、阳光窗台、草本叶片、片剂特写、量体重的秤。

## 详情页（detail_page）节奏

1. 首屏：单品名 + 副名 + 包装定位语原句，配该款宠物主视觉。
2. 共鸣屏：描述铲屎官的日常关注点（如“换季想给毛孩子多一份呵护”），只写主人的感受和宠物的日常状态，不写病症。
3. 品牌屏：辰荣贝康·中式草本宠物护理，三条品牌标语。
4. 配方屏：该款草本原料逐一列出（客观原料名），配原料实物图。
5. 工艺屏：植物精心制备与浓缩 + 风味片剂。
6. 好喂屏：鸡肝粉风味、小片剂、可直接喂或碾碎拌粮。
7. 成分屏：维生素保证值表、水分 ≤8%。
8. 用法屏：按体重喂食，详见包装说明；附注意事项原文（含禁用提示）。
9. 资质屏：符合宠物饲料卫生规定、生产企业、生产许可证号、执行标准。
10. 规格与售后屏：0.4g×30 片、24 个月保质期、储存方法、售后电话。

每屏都要写清“这一屏让用户相信什么”（写在 `selling_point`）。屏数受限时，合并 3+5、7+9。

# 生图模式判定法则（必须严格遵守）

对每个槽位只能选择以下一种 `generation_mode`，并在 `required_references` 中列出与模式数量一致的参考图角色：

| 模式 | 参考图数量 | 何时使用 |
|---|---|---|
| `text_to_image` | 0 | 画面中**不需要出现真实包装、真实片剂或真实文字证据**：宠物生活氛围、草本原料空镜、共鸣场景 |
| `single_image_edit` | 1 | 画面主体是**单个真实元素**，需保真：包装海报、片剂特写、配料表特写、白底图 |
| `multi_image_fusion` | 2~3 | **多个真实元素同框**且都要保真：包装 + 宠物模特、包装 + 片剂、包装 + 检测报告 |

判定步骤：

1. 列出该画面中“必须和实物一模一样”的元素。
2. 0 个 → `text_to_image`；1 个 → `single_image_edit`；2~3 个 → `multi_image_fusion`；超过 3 个 → 拆成两个槽位。
3. 参考图角色优先使用：`product_package`、`product_content`、`ingredient_label`、`inspection_report`、`pet_model`。系列全家福使用新角色 `series_lineup`（7 盒并排正面照）。
4. **包装盒上的品牌名、单品名、logo 必须来自 `product_package` 参考图**，严禁 AI 凭空画包装；配料表、维生素数值、许可证号、检验合格章必须来自 `ingredient_label` 或 `inspection_report`。
5. 同一角色在整组中尽量复用，减少用户需要拍摄的参考图种类。

# 防雷同规则

- 同一组内任意两个槽位的**主视角、景别、背景、主色调**不能有 3 项以上相同。
- 景别要有变化：全景（居家场景）/ 中景（宠物 + 包装）/ 特写（片剂）/ 微距（草本原料）至少覆盖 3 种（主图 ≥5 张时）。
- 每个槽位的 `selling_point` 必须不同（白底图除外）；“匠心”“臻选”“甄选好物”每组最多出现 1 次。
- 不要“宠物抱着药瓶”“白大褂医生”这类医疗感模板；每个槽位写出一个“这张图和别家不一样的地方”（写在 `differentiator`）。

# 文案规则

- 主图标题 ≤ 12 个汉字，副标题 ≤ 18 个汉字；详情页每屏标题 ≤ 14 个汉字，正文 ≤ 60 个汉字。
- 风格遵循平台 `copy_style`；口吻温和、像铲屎官之间的分享，例如“小片一颗，凑过来就吃”，而不是“强效呵护”。
- 需要上图的中文文字写在 `copy_text`，画面描述 `visual_description` 中只描述画面，不重复写文案。
- `visual_description` 写清：主体、构图、景别、光线、背景、道具、色调，并注明该款包装主色。
