# 电商高转化文案写作指南（策划 Skill 附属指南）

> 提炼自《电商高转化商品文案写作法则与进阶指南》。示例取自张家界莓茶与宠物营养补充剂，只示意写法，换类目时替换成本类目的事实。
>
> **优先级**：合规红线（卡带红线、类目 `compliance_rules` / `forbidden_words`）> 用户策划想法 > 卡带文案规则（含字数上限）> 本指南。本指南只管怎么写文案，输出格式仍按上文卡带要求只输出 JSON。
>
> **数字铁律**：含量、倍数、海拔、温度、百分比、耐泡次数、价格、份量等可核验的数字，只能来自商品信息、类目配置或检测报告，没有来源就不写数字。感官体验里的时间约数（如“三秒回甘”）可以用。售后承诺（包退、破损包赔、包邮）只能来自用户填写的商品信息。

电商文案不是文学创作，是“消费心理公式 + 感官翻译”。美工让买家停下来看，文案决定买家掏不掏钱。

## 〇、第 0 定律（写法总纲）：不卖“东西”，卖人的恐惧、欲望、体面、愧疚与想象

> 本定律排在下面所有写法规律之前，但仍在上文优先级中的合规红线之下：情感钩子写得再狠，也不碰疾病、疗效和违禁词。

有个卖宠物用品的商家，猫窝 199 元一个，卖得一般。后来他把详情页里“纯棉、可拆洗、加厚”这些词全部弱化，换成一句话：“让它别再睡纸箱了。”同一个猫窝，销量起来了。买家买的不是棉花和尺寸，是脑子里那只蜷在纸箱里、有点可怜的自家猫。健身房卖的是“我还能变回以前”，保险卖的是“万一出事别拖累家里”。

| 段位 | 在卖什么 | 写法 | 结局 |
|---|---|---|---|
| 低手 | 物理参数 | 纯棉、加厚、克重、尺寸、0.4g × 30 片 | 合规，但买家毫无波澜：“这跟我有什么关系？” |
| 蠢手 | 违规疗效 | 治病、消炎、降三高 | 违规下架 |
| 高手 | 人心 | 先用一句话唤醒买家心里的画面（愧疚补偿、害怕失去、社交体面、美好想象），再用配方、工艺、资质这些硬证据承接这份信任 | 完全合规，买家一眼对号入座 |

- **钩子在前，证据在后**：参数不是不要，而是放到钩子后面当证据（见下文 FAB 翻译）。
- **钩子从生活画面与关系里来**：写人和宠物、人和家人之间的瞬间，不写病情后果，也不吓唬人（不写“再不买就晚了”“拖成大病”）。
- ✅（猫窝）让它别再睡纸箱了。
- ✅（宠物营养品）它陪了你这么多年，现在换你陪它慢慢变老。
- ✅（莓茶送长辈）老爸嘴上永远说“别乱花钱”，转头却把你寄的这罐白霜茶，得意地拿给每个老伙计泡了一遍。
- ✅（莓茶自饮）陪客户喝了半宿言不由衷的酒，回到家泡开的这一杯清润回甘，才是真正留给自己的。

### 猫窝测试（主图首图、详情页首屏与共鸣屏、短视频前 3 秒钩子必过）

写完先问一句：这句是在干巴巴地报参数（卖棉花），还是戳中了买家心底那个舍不得、怕失去、想体面的瞬间（别睡纸箱）？是前者就重写。

## 一、动笔前的五条规律

### 1. FAB 翻译：把参数翻译成买家得到的好处

- **F 属性**（它是什么）→ **A 优势**（为什么比别家好）→ **B 利益**（买家能得到什么感受或便利）。
- 上图文案优先写 B，F 作为证据跟在后面。
- **B 只写感官体验、使用便利、省心与体面，不写身体机能变化**。食品、代用茶、宠物营养品一旦写身体作用就违规。
- 检验：写完一句，替买家问一句“那又怎样？”。买家还得自己想“这对我有什么用”，就重写。

| 类目 | F 属性 | A 优势 | B 利益 |
|---|---|---|---|
| 莓茶 | 武陵山区高海拔云雾产区、嫩芽嫩叶 | 叶面自然析出的白霜多、少粗梗 | 抓一把指尖沾满白霜，泡开金黄透亮，入口微苦三秒回甘，饭后一杯清清爽爽 |
| 宠物营养品 | 鸡肝粉风味小片剂 | 有肉香、片小 | 放在手心，它自己凑过来叼走，每天喂得省心 |

### 2. 五感具象：砍掉形容词，换成动作和微观细节

句式：**具体动作 + 微观视觉 / 触觉参照 + 身体即时反馈**（反馈指“咽下去满嘴回甘”这类感官反应，不是功效）。

| 写什么 | ❌ 形容词堆砌 | ✅ 动作 + 五感 |
|---|---|---|
| 干茶白霜 | 白霜丰富，品质上乘，天然健康 | 手指轻轻一捻，指腹沾满银白色的霜 |
| 冲泡过程 | 冲泡方便，汤色好看，茶香四溢 | 热水高冲入杯，白霜一下溶开，汤色慢慢透出金黄 |
| 口感体验 | 口感醇厚，回甘持久，非常好喝 | 头一口微苦，咽下三秒，喉间泛起清润回甘 |
| 宠物适口性 | 适口性好，营养丰富 | 打开盒子一股鸡肝香，挑嘴的小家伙闻两下就叼走了 |

### 3. 精准场景 + 痛点点名：让买家觉得“说的就是我”

句式：**具体时间 + 具体地点 + 具体的不舒服状态 → 产品出现 → 感官结果**。

- ❌ 居家办公必备，老少皆宜。
- ✅ 昨晚火锅烧烤吃多了，早上嘴里发腻？泡一杯，清清爽爽开始一天。
- ✅ 下午三点对着电脑，白开水没味、奶茶怕胖？桌上备一罐，续水喝一下午。
- ✅（宠物）每天早上倒粮时顺手放一片，日常呵护不用特意记。

痛点只写生活状态与感受（油腻、寡淡、怕胖、挑食、喂得费劲），不写疾病、症状和身体改善。面向用嗓多、熬夜加班、烟酒应酬的人群时，也只写“场景 + 口感”，例如“讲了一下午课，来一杯不甜不腻的”，不写对嗓子、睡眠、肝胃的任何作用。

### 4. 诚实预期管理：先交底，信任翻倍

把产品客观存在的特点大大方方提前说清，能过滤错误预期、减少差评。交底只讲口感、外观、使用方式，交底之后紧跟一个让人安心的理由。

- ✅ 先跟您交个底：正宗莓茶头一口不是甜的，有一丝山野的微苦，停在舌尖几秒，回甘才上来。
- ✅ 罐底会有少量自然脱落的白霜末，那是从嫩叶上抖落的，冲泡时连霜末一起倒进杯里。
- ✅（宠物）先说实话：特别挑嘴的毛孩子头一回可能只闻不吃，碾碎拌进主粮就好。

### 5. 平台语境分流：见什么人说什么话

平台配置的 `copy_style` 优先，下表是落笔手法：

| 平台 | 买家心态 | 写法 | 示例 |
|---|---|---|---|
| `pinduoduo` | 滑得最快，算账 | 大字直给利益点 + 份量感 + 售后兜底（仅限用户填写的售后） | `抓一把沾满白霜` / `张家界高山嫩芽·续水仍回甘` |
| `taobao` | 货比三家，看为什么值这个价 | 选购科普建立标准，突出等级差异与证据 | `只取春夏嫩芽尖` / `微距看清真白霜·少梗少碎末` |
| `wechat_shop` | 熟人推荐，重体面与信任 | 温和真诚的买手口吻，带一点山野意境或礼赠温度 | `一盏莓茶，半山云雾` / `送长辈的，是武陵山里的一份清润回甘` |

## 二、主图与详情页的结构公式

### 主图：一张图只讲一件事（字数上限以卡带文案规则为准）

主图在手机搜索缩略图里看，字多必死。

| 作用 | 文案公式 | 示例（莓茶） |
|---|---|---|
| 搜索首图：身份 + 第一利益点 | 【核心视觉特征】+ 产地 / 品类定语 | `满披白霜·高山嫩芽` / `张家界产区·入口微苦三秒回甘` |
| 视觉锤：放大独特质地 | 【感官动作】+ 为什么这么好 | `手指一捻·沾满白霜` / `天然黄酮结晶·霜多芽嫩` |
| 体验：冲泡 / 食用瞬间 | 【视觉或味觉特征】+ 使用场景 | `汤色金黄·清澈透亮` / `先微苦后回甘·饭后一杯清爽` |
| 源头：为什么这里长得好 | 【产地环境】+ 买家能感到的结果 | `云雾峰林里长出来` / `昼夜温差大·嫩叶霜多` |
| 对比：为什么选我 | 【好货标准】vs【常见问题】，客观科普 | `好莓茶看三点` / `看霜·看条索·看汤色` |
| 定心丸：证据 / 规格 | 【可验证证据或硬规格】+ 售后兜底 | `第三方检测·报告可查` / `源头直发·独立罐装` |

### 详情页：线上导购的说服顺序

把详情页想成买家走进你的店，你一步步打消顾虑：

1. 钩子屏：点出日常状态（饭后油腻、白开水寡淡），亮出产品。
2. 视觉锤屏：放大质地，让买家觉得“好东西一眼就看得出来”。
3. 源头信任屏：带他去产地看一看，讲清为什么这里长得好。
4. 选购对比屏：转化率最高的一屏。客观教买家自己认好货，不点名、不贬低同行。
5. 口感 / 使用体验屏：讲清真实口感（含诚实交底）。
6. 工艺与洁净屏：关键工序与干净无杂质。
7. 证据屏：检测报告原数据、机构、编号，不加工、不夸大解读。
8. 使用指南 + 规格售后屏：怎么泡（喂）最好、规格多少、售后怎么兜底，促成下单。

每屏的 `title` 写结论，`copy_text` 给 1 个感官细节 + 1 个证据；`selling_point` 写“这一屏让买家相信什么”。

## 三、写完后的四道自检

1. **套话清零**：匠心、臻选、甄选、高品质、品质卓越、非常好喝、口感醇厚、营养丰富、高端大气、原生态、天然健康等，出现就换成有来源的数字、动作或感官细节。整套方案合计最多保留 1 处。
   - ❌ 非遗匠心工艺 → ✅ 杀青、揉捻、烘干，一道道守着火候，留住叶面的白霜
   - ❌ 非常耐泡 → ✅ 早上抓一小撮，续水到下午还有回甘
2. **朗读测试**：出声读一遍，像不像当面跟老朋友说话。“本品甄选武陵山脉显齿蛇葡萄，汤色明艳，滋味醇和”不及格；“你尝尝，头一口有点苦，咽下去满嘴回甘”及格。人文意境风的句子也要短、顺口。
3. **So what 测试**：每个槽位的 `title` 或 `subtitle` 至少有一处写的是买家利益（B），不能整句都是参数（F）。
4. **买家原话优先**：类目配置的 `sensory_vocabulary`、`pain_points` 和用户想法里的买家口语，优先直接化用，比自己憋出来的形容词更能打动人。
