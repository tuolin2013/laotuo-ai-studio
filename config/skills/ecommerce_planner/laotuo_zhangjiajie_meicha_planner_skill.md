# 莓茶类目认知（策划前先吃透）

1. **白霜是第一视觉锤**：叶面自然析出的白色结晶（黄酮类物质结晶）是莓茶区别于普通绿茶的最直观特征，“霜越多越嫩”是消费者的选购共识。白霜必须用真实干茶参考图呈现，严禁 AI 凭空画霜。
2. **产区是信任基础**：张家界武陵山区、石英砂岩峰林、终年云雾。产区画面可以文生图做氛围，但不得出现可被误认为“实拍认证”的文字或标识。
3. **口感要讲清“先苦后甘”**：入口微苦、回甘明显、清爽解腻。用“回甘”“清爽”“不腻口”表达，避免“甜”这种会被差评打脸的词。
4. **冲泡门槛低**：85~95℃ 热水即泡，汤色黄绿透亮，可冷泡、可续泡。办公室、饭后、自驾出游是高频场景。
5. **数值只来自检测报告**：黄酮含量等数据只能引用 `product_info_json` 中用户填写的值，并配合 `inspection_report` 参考图出现；用户未填写则不写任何数值。

# 合规红线（违反任意一条即视为策划失败）

- 莓茶是代用茶 / 普通食品，**禁止任何功效宣传**：降三高、降血压、降血糖、降血脂、抗癌、消炎、护肝、治疗咽炎、解酒护胃等，包括“辅助”“调理”“改善”这类变相表述。
- 禁止绝对化用语：最、第一、国家级、顶级、极品、唯一。
- 黄酮只能写“含量 xx%（以检测报告为准）”，不得写黄酮的任何药理作用。
- 不得贬低其他商家或产区（如“别家都是假莓茶”），对比只能用“选购小知识”的口吻讲客观特征。
- 严禁出现类目与平台配置中的 `forbidden_words`，严格遵守 `compliance_rules`。

# 策划方法

平台配置中的 `visual_style_weights`（0~1）表示该平台对信息密度、品质质感、价格冲击、生活氛围的偏好权重，权重越高，相关槽位占比越大。例如拼多多价格冲击权重高时，首图可加入规格/到手价信息；微信小店生活氛围权重高时，多给办公、送礼场景。

## 主图组（main_image）节奏

| 位置 | 作用 | 莓茶推荐画面 | 推荐模式 |
|---|---|---|---|
| 第 1 张 | 搜索首图，1 秒可读 | 包装 + 满霜干茶同框，一个核心利益点大字（如“满霜嫩芽”） | `multi_image_fusion`（product_package + dry_leaf_closeup） |
| 第 2 张 | 白霜视觉锤 | 干茶微距，霜层颗粒清晰，侧逆光 | `single_image_edit`（dry_leaf_closeup） |
| 第 3 张 | 汤色与口感 | 透明玻璃杯茶汤，黄绿透亮，杯壁挂少量水汽 | `single_image_edit`（tea_soup）或与包装融合 |
| 第 4 张 | 产区信任 | 张家界峰林晨雾 / 茶园实景 | 有 origin_scene 用 `single_image_edit`，否则 `text_to_image` |
| 第 5 张 | 证据 | 包装 + 检测报告同框 | `multi_image_fusion`（product_package + inspection_report） |
| 末段 | 场景 / 规格 / 白底 | 办公室一杯、冷泡、送礼礼盒、白底图（按平台要求） | 视画面判定 |

张数不是 5 张时按此优先级增减：首图 > 白霜 > 汤色 > 证据 > 产区 > 场景 > 规格。

## 详情页（detail_page）节奏

1. 首屏钩子：饭后油腻 / 白开水寡淡 / 含糖饮料怕胖，给出“来一杯清爽回甘的山野茶”。
2. 白霜屏：讲清白霜是什么、怎么看霜（选购小知识口吻）。
3. 产区屏：武陵山区、海拔与云雾环境，配用户填写的具体产区。
4. 原料与工艺屏：芽头嫩叶、杀青揉捻烘干，条索完整。
5. 口感屏：先微苦后回甘，清爽不腻口。
6. 证据屏：检测报告（必须用参考图），可引用用户填写的黄酮含量。
7. 冲泡屏：热泡（85~95℃）、冷泡、续泡三种方式图解。
8. 场景屏：办公室、饭后、出游、送长辈。
9. 规格与包装屏 → 售后与保障屏。

每屏都要写清“这一屏让用户相信什么”（写在 `selling_point`）。屏数受限时，合并 4+5、7+8。

# 生图模式判定法则（必须严格遵守）

对每个槽位只能选择以下一种 `generation_mode`，并在 `required_references` 中列出与模式数量一致的参考图角色：

| 模式 | 参考图数量 | 何时使用 |
|---|---|---|
| `text_to_image` | 0 | 画面中**不需要出现真实商品包装、真实干茶或真实文字证据**：痛点场景、产区风光、氛围空镜 |
| `single_image_edit` | 1 | 画面主体是**单个真实元素**，需保真：包装海报、干茶微距、茶汤特写、白底图 |
| `multi_image_fusion` | 2~3 | **多个真实元素同框**且都要保真：包装 + 干茶、包装 + 茶汤、包装 + 检测报告 |

判定步骤：

1. 列出该画面中“必须和实物一模一样”的元素。
2. 0 个 → `text_to_image`；1 个 → `single_image_edit`；2~3 个 → `multi_image_fusion`；超过 3 个 → 拆成两个槽位。
3. 参考图角色优先使用：`product_package`、`dry_leaf_closeup`、`tea_soup`、`inspection_report`、`origin_scene`。确有需要的新角色，用小写英文下划线命名并在 `description` 中写清拍摄要求。
4. **只要画面出现白霜特写，就必须绑定 `dry_leaf_closeup`**；只要出现检测数据或印章，就必须绑定 `inspection_report`。
5. 同一角色在整组中尽量复用，减少用户需要拍摄的参考图种类。

# 防雷同规则

- 同一组内任意两个槽位的**主视角、景别、背景、主色调**不能有 3 项以上相同。
- 景别要有变化：全景（峰林）/ 中景（茶桌）/ 特写（茶汤）/ 微距（白霜）至少覆盖 3 种（主图 ≥5 张时）。
- 绿色不要全组铺满：山林绿、云雾白、茶汤黄绿、原木色轮换做主色。
- 每个槽位的 `selling_point` 必须不同（白底图除外）；“匠心”“臻选”“原生态”每组最多出现 1 次。
- 不要千篇一律的“茶叶撒满桌面 + 紫砂壶”模板；每个槽位写出一个“这张图和别家不一样的地方”（写在 `differentiator`）。

# 文案规则

- 主图标题 ≤ 12 个汉字，副标题 ≤ 18 个汉字；详情页每屏标题 ≤ 14 个汉字，正文 ≤ 60 个汉字。
- 风格遵循平台 `copy_style`；口语、具体、有画面感，例如“抓一把，手指沾满霜”，而不是“品质卓越”。
- 需要上图的中文文字写在 `copy_text`，画面描述 `visual_description` 中只描述画面，不重复写文案。
- `visual_description` 写清：主体、构图、景别、光线、背景、道具、色调；道具优先从类目 `visual_style.props` 中选。
