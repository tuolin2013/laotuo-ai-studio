# 莓茶类目深度认知（策划前先吃透）

1. **白霜是第一视觉锤**：叶面自然析出的银白色结晶（天然植物黄酮结晶）是莓茶区别于普通茶的最直观特征，”满披白霜、霜厚芽嫩”是消费者的核心选购共识。**铁律：凡画面出现干茶白霜特写，必须使用真实干茶参考图呈现，严禁让 AI 凭空文生图画霜！**

2. **产区是信任基础**：张家界武陵源/核心石英砂岩峰林山区、高海拔溪谷、终年云雾缭绕。产区画面可用文生图做大气自然风光氛围，但不得出现伪造的”官方认证奖牌/证书”文字。

3. **汤色与叶底特征**：85~95℃ 沸水冲泡后，表面白霜迅速溶入水中，茶汤呈**金黄透亮 / 明黄微绿的琥珀光感**（切忌描述成浑浊深绿或浓红茶色）；泡开后的叶底肥嫩鲜活、条索完整。

4. **口感要讲清”先微苦后回甘”**：入口微苦、转瞬回甘、清爽解腻。用”回甘””清润””清爽不腻口”表达，避免单写”很甜”导致买家预期偏差。

5. **产品等级与包装形态自适应**：
   - 先看 `product_info_json` 中的等级（如”芽尖/龙须/特级”）与包装形态（”礼盒装/罐装/袋装/独立小茶包”）：
   - 若为**芽尖 + 礼盒装**：重点强化”采摘娇嫩芽头、满霜品相、送长辈/商务体面礼赠”；
   - 若为**龙须/罐装/袋装口粮茶**：重点强化”耐泡度、办公室玻璃杯随手泡、饭后解腻、高性价比足量”。

6. **数值只来自检测报告**：总黄酮含量等具体百分比数据只能引用 `product_info_json` 中用户填写的真实值，并强制绑定检测报告参考图出现；用户未填写具体数值时，严禁编造任何百分比数字。

# 合规红线（违反任意一条即视为策划失败）

- 莓茶属于代用茶（普通食品），**严禁出现任何医疗与保健功效宣传**：降三高、降血压、降血糖、降血脂、抗癌、消炎、杀菌、护肝、清肺、治疗咽炎/慢性咽炎、解酒护胃、安神助眠、提高免疫力等，**包含”辅助””调理””改善””预防””养生神茶”等擦边变相表述一律禁止**。
- 严禁绝对化与极限用语：最、第一、国家级、顶级、极品、唯一、茶王、冠绝。
- 黄酮表述规范：只能客观陈述”天然植物黄酮结晶”或”总黄酮含量 xx%（数据源自检测报告）”，不得解释黄酮的任何药理或治病作用。
- 严禁恶意贬低同行（如”别家都是假莓茶/硫熏茶”），对比屏只能用”莓茶选购小知识：好莓茶怎么看”的客观科普口吻。
- 严禁出现类目与平台配置中的 `forbidden_words`，严格遵守 `compliance_rules`。

# 生图模式判定与参考图角色对齐法则（核心铁律）

对每个槽位只能选择以下一种 `generation_mode`，且 `required_references` 数组长度必须与模式严格匹配：

| 模式 | `required_references` 数量 | 何时使用 |
|---|---|---|
| `text_to_image` | **0 个**（空数组 `[]`） | 画面中**不出现真实包装、真实干茶白霜或检测报告**：如张家界峰林云海、茶园风光、饮茶生活氛围、痛点场景 |
| `single_image_edit` | **精确 1 个** | 画面只需保真还原 **1 样真实物品**：单独展示包装海报、干茶白霜光学微距、玻璃杯茶汤特写、规格图 |
| `multi_image_fusion` | **2~3 个** | 画面需 **2~3 样真实物品同框合成**：如「包装 + 干茶微距」、「包装 + 金黄茶汤」、「包装 + 检测报告」 |

**参考图角色 ID 命名规范（保证系统自动汇总与跨模块复用不断裂）：**

1. 请优先从上方传入的 `category_json` 的 `reference_image_roles` 中选取最匹配的 `role` 标识；
2. 若配置中未限定，统一使用以下标准英文标识（整套方案内同名角色自动去重复用）：
   - `product_package`（商品外包装正面/立体实拍图）
   - `dry_leaf_closeup`（干茶微距实拍图——**凡画面强调白霜结晶，必须绑定此角色！**）
