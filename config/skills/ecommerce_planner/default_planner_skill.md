# 策划方法 {#planning_rhythm}

## 主图组（main_image）节奏

1. 第 1 张：搜索首图。主体清晰、背景干净、一个核心利益点大字，手机小图下 1 秒可读。
2. 第 2~3 张：核心卖点可视化（如白霜微距、茶汤色泽、适口性），一张图只讲一个点。
3. 中段：证据与信任（产地、工艺、检测报告、成分表）。
4. 末段：使用场景 / 规格 / 赠品 / 白底图（按平台要求）。

平台配置中的 `visual_style_weights`（0~1）表示该平台对信息密度、品质质感、价格冲击、生活氛围的偏好权重，权重越高，相关槽位占比越大。

## 详情页（detail_page）节奏

首屏钩子（痛点或核心利益）→ 卖点逐屏展开（一屏一点）→ 产地与工艺故事 → 证据屏（检测报告、成分表）→ 使用/冲泡方法 → 规格与包装 → 售后与保障。每屏都要有明确的“这一屏让用户相信什么”。

# 生图模式判定法则（必须严格遵守） {#generation_mode}

对每个槽位只能选择以下一种 `generation_mode`，并在 `required_references` 中列出与模式数量一致的参考图角色：

| 模式 | 参考图数量 | 何时使用 |
|---|---|---|
| `text_to_image` | 0 | 画面中**不需要出现真实商品包装或真实文字证据**：痛点场景、产区风光、氛围空镜、生活方式概念图 |
| `single_image_edit` | 1 | 画面主体是**单个真实商品**，需保真包装与 logo：单主体海报、商品微距、白底图、换背景 |
| `multi_image_fusion` | 2~3 | 画面需要**多个真实元素同框**且都要保真：包装 + 茶汤、包装 + 内料、包装 + 检测报告、包装 + 宠物模特 |

判定步骤：

1. 列出该画面中“必须和实物一模一样”的元素。
2. 0 个 → `text_to_image`；1 个 → `single_image_edit`；2~3 个 → `multi_image_fusion`；超过 3 个 → 拆成两个槽位。
3. 参考图角色只能使用类目配置 `reference_image_roles` 中的键名；确有需要的新角色，用小写英文下划线命名并在 `description` 中写清拍摄要求。
4. 检测报告、成分表等**真实证据**必须走参考图，严禁让模型凭空生成数据或印章。

# 防雷同规则 {#anti_duplicate}

- 同一组内任意两个槽位的**主视角、景别、背景、主色调**不能有 3 项以上相同。
- 景别要有变化：全景 / 中景 / 特写 / 微距至少覆盖 3 种（主图 ≥5 张时）。
- 标题文案不得重复同一卖点的同义改写；每个槽位的 `selling_point` 必须不同（白底图除外）。
- 避免同质化电商模板词：“匠心”“臻选”“甄选好物”等每组最多出现 1 次。
- 不得照搬竞品常见构图；每个槽位写出一个“这张图和别家不一样的地方”（写在 `differentiator`）。

# 视觉设计三维体系（每个槽位必须给出） {#visual_system}

每个槽位都要选定一个美学流派 `aesthetic_style` 和一个构图模式 `composition_mode`。生图 Skill 会据此决定色板、光线、中文字体，以及文字排在哪块留白区。

美学流派（5 选 1）：

| 代码 | 名称 | 适合的槽位 | 视觉要点 |
|---|---|---|---|
| `new_chinese_zen` | 新中式茶席禅意 | 高端礼盒、东方茶饮、送礼 | 深苍山绿 / 暖炭黑底，宋刻衬线体 + 朱砂小印章 |
| `organic_nature_sunlight` | 原生态山野呼吸 | 产地溯源、天然原料、日常口粮 | 晨雾白 / 嫩芽绿，清晨通透自然光 |
| `clinical_lab_minimal` | 科学实证极简 | 检测报告、成分表、规格参数、客观对比 | 冰川白 / 科技浅灰，无影棚拍，现代粗黑体 |
| `nordic_warm_lifestyle` | 北欧暖阳治愈 | 居家 / 办公使用场景、宠物互动、痛点共鸣 | 奶油米白 / 燕麦色，午后暖阳窗影，亲和圆黑体 |
| `high_impact_retail` | 高对比零售视觉锤 | 拼多多首图、大促、规格全家福 | 翡翠深绿或赤金红底，明黄大字，强轮廓光 |

构图模式（6 选 1）：

| 代码 | 名称 | 适合的槽位 | 主体与留白 |
|---|---|---|---|
| `rule_of_thirds_negative_space` | 三分留白 | 首图、首屏海报、产地大景 | 主体在右下或左下三分点（约 55%），对角侧 30%~40% 留白 |
| `extreme_macro_texture` | 光学微距满画幅 | 质地、原料、细节特写 | 质地占 65%~75%，一角 25%~30% 柔焦留白 |
| `depth_layering` | 前中远三层景深 | 多图融合、冲泡 / 喂食体验 | 前景虚化道具 + 中景主体清晰 + 远景虚化，顶部约 30% 留白 |
| `diagonal_dynamic_flow` | 对角线动态 | 冲泡、倾倒、使用瞬间 | 动作沿 45° 对角线，另一侧三角区约 30% 留白 |
| `split_screen_comparison` | 分屏对比 | 选购小知识、客观对比 | 70% 本品 vs 30% 普通对照，顶部 20% 标题区；只做客观科普，不贬低同行 |
| `knolling_flat_lay` | 90° 俯拍秩序 | 检测背书、规格全家福、参数屏 | 正上方俯拍网格陈列，上方 25%~30% 留白 |

选择规则：

1. 指令末尾如果有「全局美学流派」段落，所有槽位的 `aesthetic_style` 都用它；否则按每个槽位的作用、类目与平台调性选择，整组建议控制在 2~3 种流派，保持统一感。
2. 用户策划想法里提到的色调或风格优先（例如「暖金色调」可选新中式或北欧暖阳）。
3. `visual_description` 必须写出主体位置、占比，以及文字留白区的位置和大小（例如「主体位于右下三分点约占 55%，左上方预留约 35% 柔焦云雾留白区排版标题」）。留白区不得压在包装、内料细节或检测报告上。
4. 平台白底图等规范图不需要留白构图，`composition_mode` 填 `auto`。
5. 只能填上表中的代码或 `auto`，不要自造新值。

# 文案规则 {#copywriting}

- 主图标题 ≤ 12 个汉字，副标题 ≤ 18 个汉字；详情页每屏标题 ≤ 14 个汉字，正文 ≤ 60 个汉字。
- 严禁出现类目与平台配置中的 `forbidden_words`，严格遵守 `compliance_rules`。
- 风格遵循平台 `copy_style`。
- 需要上图的中文文字写在 `copy_text`，画面描述 `visual_description` 中只描述画面，不重复写文案。

写法细则见指令后附的《电商高转化文案写作指南》，核心五条：

1. **FAB 翻译**：先理清 F（属性）→ A（优势）→ B（买家利益），上图文案优先写 B。B 只写感官体验、使用便利、省心与体面，不写身体作用。写完替买家问一句“那又怎样？”，答不上来就重写。
2. **五感具象**：用“具体动作 + 微观视觉/触觉 + 感官即时反馈”代替形容词，优先化用类目配置 `cultural_context` 中的感官词汇。
3. **场景点名**：痛点与场景槽位写“具体时间 + 地点 + 不舒服的生活状态”，不写疾病、症状与身体改善。
4. **诚实交底**：可主动说清产品客观存在的特点（口感、外观、使用方式），再给一个让人安心的理由。
5. **数字铁律**：含量、倍数、价格、份量、售后承诺只能来自商品信息、类目配置或检测报告，没有来源就不写。

# 自检清单（输出前逐条确认） {#self_check}

1. **`slots` 数组元素数量精确等于 `requested_count` 指定的数量（或平台默认值）**；
2. 每个槽位 `generation_mode` 与 `required_references` 数量一致（0 / 1 / 2~3）；
3. 每个槽位都有合法的 `aesthetic_style` 与 `composition_mode`，`visual_description` 写清了留白区位置；
4. 无禁用词、无功效承诺；
5. 用户想法已被落实到具体槽位中（若填写了）；
6. 每个槽位的 `title` 或 `subtitle` 至少有一处是买家利益；套话（匠心、臻选、高品质等）合计 ≤1 次；所有数字都有来源；读出来像人话。
