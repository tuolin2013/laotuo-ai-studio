# 五种内容形式的创作方法论

## lifestyle_seeding（场景种草类）

**核心**:痛点 → 场景化解决方案 → 产品自然植入

- **钩子设计**:用户痛点的强共鸣瞬间(如:办公室困到打哈欠、铲屎官被毛孩子挑食困扰)
- **情感曲线**:焦虑/困扰 → 尝试产品 → 惊喜/满足
- **场景选择**:真实生活场景,产品使用自然不刻意
- **行动号召**:强调"解决你的XX痛点"

## product_showcase（产品展示类）

**核心**:ASMR 感官刺激 + 分层展示产品细节

- **钩子设计**:强视听冲击(撕袋声、冲泡声、微距白霜、颗粒流动)
- **情感曲线**:好奇 → 惊艳 → 想拥有
- **展示节奏**:外观 → 细节 → 使用过程 → 效果呈现,每层递进
- **行动号召**:强调"亲眼看到的品质"

## trust_building（信任背书类）

**核心**:证据可信度 + 时间线叙事

- **钩子设计**:权威证据先行(检测报告特写、产地实拍第一帧、认证标志)
- **情感曲线**:质疑 → 求证 → 信任
- **证据层次**:
  - 产地溯源:从源头到成品的时间线
  - 成分检测:数据可视化 + 对比参照
  - 工艺认证:关键工序特写 + 标准展示
- **行动号召**:强调"有证据的安心"

## comparison_review（对比测评类）

**核心**:公平对比 + 差异可视化

- **钩子设计**:对比冲突(两个产品并排、数据差距、效果反差)
- **情感曲线**:疑惑 → 对比验证 → 明确选择
- **对比维度**:
  - 横向对比:同类产品 2-3 个维度(价格、成分、效果)
  - 纵向对比:使用前后的变化
  - 成分拆解:配料表逐项对比
- **公平性**:客观陈述,不踩同行,强调产品优势而非对手缺陷
- **行动号召**:强调"对比后的明智选择"

## emotional_story（情感故事类）

**核心**:人物弧光 + 情感共鸣点

- **钩子设计**:人物冲突或情感张力(匠人的坚守、用户的改变、传承的故事)
- **情感曲线**:平静 → 冲突/困境 → 转折 → 升华
- **故事结构**:
  - 品牌故事:创始人初心 → 困难 → 突破 → 使命
  - 用户故事:真实人物 → 遇到问题 → 产品介入 → 生活改变
  - 匠人精神:工艺传承 → 时代挑战 → 坚守创新 → 价值传递
- **行动号召**:强调"支持这份坚持/改变"

# 创意大纲四要素

## 1. 钩子设计 (hook_design)

前 3 秒用什么抓住用户?三选一:

- **强视听钩子**:物理声音(沸水、撕袋、咀嚼) + 微距视觉冲击
- **人物反差钩子**:反常识台词、痛点共鸣、情绪张力
- **结果先行钩子**:最惊艳画面前置(白霜溶开、对比结果、情感高潮)

要求:必须让商品或其核心特征在前 3 秒出现。

## 2. 核心信息 (core_message)

一句话说清楚这条视频要传递什么卖点。不是产品介绍,是**用户为什么要买**。

例如:
- ❌ "张家界莓茶含黄酮"
- ✅ "一杯抵 10 杯绿茶的护嗓神器"

## 3. 情感曲线 (emotional_arc)

从什么情绪到什么情绪?符合内容形式的情感设计。

例如:
- 场景种草:"困扰 → 尝试 → 惊喜"
- 信任背书:"质疑 → 求证 → 信任"
- 情感故事:"平静 → 冲突 → 升华"

## 4. 行动号召 (call_to_action)

结尾如何促成转化?语气真诚,不喊口号。

例如:
- 场景种草:"办公室常备,嗓子不干了"
- 产品展示:"这品质,你亲眼看到了"
- 信任背书:"有检测报告的,放心喝"
- 对比测评:"对比完你就知道怎么选"
- 情感故事:"支持这份手艺,别让它失传"

# 结构规划 (scenes_outline)

根据目标时长拆分 2-6 个场景/段落,每个场景一句话概述。

例如(15 秒产品展示):
1. 钩子:撕开包装,白霜扑面
2. 冲泡:沸水注入,汤色金黄
3. 特写:杯壁挂霜,黄酮可见
4. 行动号召:办公室常备罐

```

  "core_message": "一句话卖点",
  "emotional_arc": "从什么情绪到什么情绪",
  "call_to_action": "结尾行动号召(真诚不喊口号)",

  "scenes_outline": [
    "场景1一句话概述",

    "场景3一句话概述"
  ]
}
```

自检清单:

1. 钩子在前 3 秒,商品特征必须出现;
2. 核心信息是"用户为什么要买",不是产品介绍;
3. 情感曲线符合所选内容形式;
4. 场景数量 = scenes_count,每个场景概述简洁有力;
5. 用户想法已落实(若填写了)。
