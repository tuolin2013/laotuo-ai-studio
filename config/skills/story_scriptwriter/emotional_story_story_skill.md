# 情感故事类创作方法论

## 核心公式

**人物登场 → 冲突/困境 → 转折/坚守 → 情感升华 → 支持行动**

## 三种故事类型

### 1. 品牌故事

**适用**:有创始故事、创业经历的品牌

**故事结构**:
- 初心:为什么开始做这件事
- 困境:遇到什么困难(资金、技术、市场)
- 坚守:为什么没有放弃
- 突破:如何解决问题
- 使命:现在要做什么

**情感核心**:初心与坚守

**例子**:
- 创始人为家人健康,辞职回老家做有机茶
- 遇到销路困难,一度想放弃
- 想起父亲的嘱托,咬牙坚持
- 通过直播找到认可的用户
- 现在想让更多人喝到真正的好茶

### 2. 用户故事

**适用**:产品改变了真实用户的生活

**故事结构**:
- 人物:真实用户(身份、生活状态)
- 问题:遇到什么困扰(健康、宠物、生活)
- 遇见:如何接触到产品
- 改变:使用后的变化(身体、心情、生活)
- 感受:用户真实感受

**情感核心**:改变与感激

**例子**:
- 程序员长期加班,嗓子慢性咽炎
- 吃药不管用,说话都疼
- 朋友推荐莓茶,抱着试试的心态
- 喝了一个月,明显好转
- 现在成了忠实用户,推荐给同事

### 3. 匠人精神

**适用**:传统工艺、手工制作、世代传承

**故事结构**:
- 传承:这门手艺传了多少代
- 工艺:核心工序的讲究(时间、温度、手法)
- 挑战:现代工业化冲击、年轻人不愿学
- 坚守:为什么还要坚持手工
- 价值:这份坚持的意义

**情感核心**:传承与匠心

**例子**:
- 三代制茶人,70 年手工制茶
- 杀青必须手工翻炒,掌握火候靠经验
- 机器制茶更快更便宜,但味道不对
- 坚持手工,因为这是祖辈传下来的
- 希望这门手艺不要在我这代失传

## 人物弧光设计

情感故事的灵魂是**人物的变化**。

### 品牌故事的人物弧光

```
迷茫/困境(低点) → 遇到转机 → 重新出发 → 找到方向(高点)
```

- 初始状态:困惑、困难、想放弃
- 转折点:某个人、某件事、某个信念
- 最终状态:坚定、有使命感、充满希望

### 用户故事的人物弧光

```
被问题困扰(低点) → 尝试产品 → 看到改变 → 生活变好(高点)
```

- 初始状态:痛苦、焦虑、无助
- 转折点:遇到产品,决定试试
- 最终状态:问题解决,感激、满足

### 匠人故事的人物弧光

```
平静传承 → 面临挑战 → 内心挣扎 → 坚定信念(升华)
```

- 初始状态:踏实做事,不求名利
- 冲突点:时代变化,传统受冲击
- 最终状态:更加珍惜、坚守、有使命感

## 冲突设计

好故事必须有**冲突**,否则平淡无波。

### 外部冲突

- 资金困难:创业没钱、推广困难
- 市场竞争:大品牌挤压、价格战
- 技术挑战:工艺难掌握、设备落后
- 认知壁垒:用户不了解、不信任

### 内部冲突

- 坚守 vs 放弃:要不要继续做
- 传统 vs 现代:要不要改变
- 理想 vs 现实:初心与生存
- 责任 vs 自由:传承的压力

### 冲突解决

冲突不能悬而未决,要有**转折和解决**:

- 遇到贵人:有人支持、指点
- 找到方法:技术突破、新渠道
- 内心顿悟:想通了、不纠结了
- 用户认可:第一批铁粉、口碑传播

## 情感共鸣点设计

让用户产生共鸣的**触发点**。

### 常见共鸣点

1. **坚守不易**
   - "做这个不赚钱,但我不想放弃"
   - 触发:对坚持梦想的敬佩

2. **传承责任**
   - "这是爷爷传下来的,不能在我手里断"
   - 触发:对传统的珍惜、对责任的认同

3. **改变生活**
   - "以前嗓子疼得说不出话,现在好多了"
   - 触发:感同身受、希望自己也能改变

4. **初心不变**
   - "当初就想让家人吃得安心,现在想让更多人吃得安心"
   - 触发:对善良和真诚的感动

5. **时代困境**
   - "年轻人都不愿学这个,太慢、太累"
   - 触发:对传统文化流失的惋惜

### 情感高潮设计

在 **80% 时间点**设置情感高潮:

- 人物说出最触动人心的话
- 配合画面(特写、慢镜、意境)
- 音乐情绪配合(如果有)
- 之后迅速收尾,给行动号召

## 对白设计

情感故事的对白要**真实、有温度、不煽情**。

### 真实感原则

1. **用口语,不文艺腔**
   - ❌ "我在寻找人生的意义"
   - ✅ "那时候真的想不通,不知道为啥要这么累"

2. **说细节,不空洞**
   - ❌ "创业很辛苦"
   - ✅ "那年冬天,仓库没暖气,手都冻裂了"

3. **有情绪,不煽情**
   - ❌ "我哭了,我感动了"
   - ✅ "后来那个用户给我发消息说谢谢,我当时...就觉得值了"

### 对白节奏

- 开头:平缓,交代背景
- 冲突:语速加快,情绪起伏
- 高潮:放慢,一字一句,情感浓
- 收尾:坚定,给出行动号召

### 旁白 vs 人物独白

情感故事可以有**旁白**(与 H3 原生声音不同,这是**画外音/配音**),但要慎用:

- 品牌故事:创始人独白(同期声更真实)
- 用户故事:用户自述(同期声)
- 匠人故事:旁白 + 匠人语录(结合使用)

## 视觉语言

情感故事的画面要有**意境和温度**。

### 画面选择

- 人物特写:捕捉表情、眼神
- 工作场景:展现专注、投入
- 环境空镜:烘托情绪(晨曦、夕阳、山林)
- 细节特写:手、工具、产品

### 光线情绪

- 温暖:暖调、逆光、柔和
- 坚毅:硬光、侧光、对比强
- 希望:晨光、明亮、清新

### 运镜节奏

- 平静:缓慢推进、移动
- 冲突:手持、晃动(轻微)
- 升华:稳定、上升、开阔

## 情感节奏

情感故事的情感曲线:

```
平静(开场) → 冲突(下降) → 坚守(回升) → 升华(高潮) → 行动号召(稳定)
```

控制节奏,不要一直高潮,否则麻木。

# 合规

情感故事类要注意:

1. **故事必须真实**
   - 不得虚构经历、夸大困难
   - 用户故事要经过本人同意

2. **不煽情不贩卖焦虑**
   - 不过度渲染苦难
   - 不道德绑架("不买就是不支持")

3. **产品信息真实**
   - 情感不能掩盖虚假宣传
   - 该有的数据、证明要有

4. **尊重隐私**
   - 用户故事要打码/化名(如需)
   - 不涉及敏感信息

# 输出格式

只输出一个合法的 JSON 对象,不要有任何前后说明文字:

```json
{
  "title": "视频标题",
  "logline": "一句话故事梗概",
  "content": "完整 Markdown 剧本(注意:content 字段内的换行符必须转义为 \\n,双引号必须转义为 \\\")",
  "characters": ["主角", "配角(如有)"],
  "locations": ["场景1", "场景2"],
  "props": ["象征性道具"]
}
```

**重要**: `content` 字段是一个 JSON 字符串,必须正确转义:
- 换行符用 `\n` 表示
- 双引号用 `\"` 表示
- 反斜杠用 `\\` 表示

自检清单:

1. 人物真实,有弧光(前后变化);
2. 冲突明确,有转折;
3. 对白真实,不煽情不空洞;
4. 情感共鸣点清晰;
5. 情感高潮在 80% 时间点;
6. 行动号召与情感自然衔接;
7. 故事真实,符合商品信息;
8. 创意大纲的钩子、核心信息已落实。
