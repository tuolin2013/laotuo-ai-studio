# 信任背书类创作方法论

## 核心公式

**权威证据先行 → 溯源/检测/认证 → 细节可验证 → 信任转化**

## 三种信任背书形式

### 1. 产地溯源型

**适用**:茶叶、农产品、地域特产

**叙事结构**:
- 钩子:产地标志性景观(张家界云海、高山茶园)
- 溯源:从源头到成品的时间线
- 细节:生长环境、采摘标准、制作工艺
- 温度:种植者/制茶人的坚守

**证据层次**:
1. 地理标识(地图、路牌、地标)
2. 生长环境(土壤、气候、海拔)
3. 采摘/收获画面(时间、标准、人工)
4. 加工过程(关键工序特写)
5. 成品溯源码(可验证)

### 2. 成分检测型

**适用**:保健品、功能性食品、宠物营养品

**叙事结构**:
- 钩子:检测报告特写(关键数据醒目)
- 对比:与普通产品/国标的数据对比
- 解读:数据意味着什么(功效、安全性)
- 信任:第三方权威机构背书

**证据层次**:
1. 检测报告封面(机构名称、日期)
2. 关键指标特写(黄酮、蛋白质、重金属等)
3. 数据对比可视化(柱状图、表格)
4. 检测机构资质(CMA、CNAS 标志)
5. 报告编号(可查询)

### 3. 工艺认证型

**适用**:传统工艺产品、高端产品、标准化产品

**叙事结构**:
- 钩子:认证标志/关键工序特写
- 展示:核心工艺流程
- 标准:遵循的行业标准/传承
- 信任:认证证书/工艺传承人

**证据层次**:
1. 认证证书/标志(有机、非遗、ISO)
2. 关键工序特写(手工/机械)
3. 时间与温度(工艺参数可视化)
4. 品控环节(检验、筛选)
5. 传承人/工程师出镜(专业背书)

## 证据可信度设计

### 什么是可信的证据

**高可信度**:
- 第三方权威机构(SGS、中国检科院、地方质检)
- 可验证信息(报告编号、溯源码、证书编号)
- 时间戳(拍摄日期、检测日期)
- 人物背书(产地农户、检测工程师、工艺师傅)

**低可信度**(避免):
- 自说自话("我们的产品很好")
- 模糊数据("含有丰富的XX")
- 无法验证的宣称
- 过度美化的广告语

### 证据展示原则

1. **先给结论,再展开细节**
   - ❌ "这是我们的茶园,在张家界,海拔800米..."
   - ✅ "张家界地理标志产品,看检测报告 → 黄酮 6.8%,是绿茶的 10 倍 → 这是产地..."

2. **数据可视化**
   - 不是念数字,而是让数据**可见**
   - 用对比、标注、图表

3. **细节可验证**
   - 给出可以查询的信息
   - 报告编号、溯源码、认证机构官网

## 叙事温度

信任背书不是冷冰冰的数据堆砌,而是有**人和故事**。

### 产地溯源的温度

- 种植者的坚守:"我爷爷那辈就种这茶"
- 环境的珍贵:"一年就采一季,不打农药"
- 传承的责任:"不能砸了祖辈的招牌"

### 成分检测的温度

- 送检的初心:"我自己家孩子也喝,必须安心"
- 数据背后的意义:"这个指标高,护嗓效果就好"
- 对用户的承诺:"每批都检,报告都能查"

### 工艺认证的温度

- 工艺人的专注:"这道工序要 12 小时,急不得"
- 标准的严格:"不达标的直接挑出来"
- 品质的坚持:"贵一点,但做得安心"

## 对白设计

### 出镜人物

信任背书类常需要**真人出镜**背书:

- 产地溯源:农户、茶农、合作社负责人
- 成分检测:创始人、品控负责人、检测工程师
- 工艺认证:工艺师傅、传承人、厂长

### 对白原则

1. **真诚,不念稿**
   - ❌ "我们的产品经过严格检测,品质优良"
   - ✅ "你看这个报告,黄酮 6.8,我自己都没想到这么高"

2. **用数据说话**
   - ❌ "很好喝"
   - ✅ "黄酮是绿茶的 10 倍,护嗓效果明显"

3. **给出可验证的信息**
   - ❌ "我们有检测报告"
   - ✅ "这是 SGS 的报告,编号在这,你可以官网查"

## 情感节奏

信任背书的情感曲线:

```
质疑(用户初始状态) → 证据呈现(开始关注) → 细节验证(产生信任) → 温度感受(信任加深) → 放心购买
```

不需要激情,而是**稳定、可靠、值得托付**的感觉。

# 合规

信任背书类对合规要求**最严格**:

1. 所有数据必须真实,有据可查
2. 不得使用"最佳""第一""唯一"等绝对化用语
3. 功效宣称必须符合广告法(尤其保健品、食品)
4. 检测报告、认证证书必须真实有效
5. 对比不得贬低同行,只陈述客观差异

# 输出格式

只输出一个合法的 JSON 对象,不要有任何前后说明文字:

```json
{
  "title": "视频标题",
  "logline": "一句话故事梗概",
  "content": "完整 Markdown 剧本(注意:content 字段内的换行符必须转义为 \\n,双引号必须转义为 \\\")",
  "characters": ["出镜人物1"],
  "locations": ["产地/实验室/工厂"],
  "props": ["检测报告", "认证证书", "产品"]
}
```

**重要**: `content` 字段是一个 JSON 字符串,必须正确转义:
- 换行符用 `\n` 表示
- 双引号用 `\"` 表示
- 反斜杠用 `\\` 表示

自检清单:

1. 核心证据清晰,来源权威;
2. 可验证信息完整(报告编号、溯源码、机构名称);
3. 数据真实,符合商品信息;
4. 叙事有温度,不是冷数据堆砌;
5. 对白真诚,不念广告词;
6. 严格遵守合规要求,无功效夸大;
7. 创意大纲的钩子、核心信息已落实。
