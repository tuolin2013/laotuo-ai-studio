# 场景种草类创作方法论

## 核心公式

**痛点具象化 → 尝试时刻 → 效果惊喜 → 行动号召**

## 三大原则

### 1. 痛点要真实可感

不是空泛描述,而是具体场景:

- ❌ "工作累了"
- ✅ "下午3点连开两个会,白开水喝不下,奶茶又怕胖"

- ❌ "猫咪挑食"
- ✅ "新粮放了3天,一口没动,眼巴巴看着你"

### 2. 产品植入要自然

不是硬广,而是解决方案的自然出现:

- ❌ "我买了XX品牌莓茶"
- ✅ "同事递过来一杯,说头一口有点苦,你等三秒"

- ❌ "给它吃XX保健品"
- ✅ "倒粮时顺手放一片,它闻着鸡肝香自己凑过来"

### 3. 效果要有反差

用视觉、听觉、情绪的对比制造惊喜:

- 视觉反差:冲泡前后、使用前后
- 听觉反差:咕咚喝水声、满足叹气声
- 情绪反差:焦虑 → 惊喜 → 满足

## 人物设定

场景种草类需要真实人物,不是产品演示。

**常见人物原型**:
- 办公室打工人(不甜不腻的日常饮品)
- 新手铲屎官(宠物食品、保健品)
- 养生党(健康食品、滋补品)
- 宝妈(儿童食品、家庭囤货)

人物要有:
- 身份标签(如:设计师、运营、程序员)
- 痛点具体场景(如:连续开会3小时)
- 真实反应(如:惊讶、满足、想分享)

## 对白设计

### 语气真实,不念广告词

- ❌ "这款产品含有丰富的黄酮"
- ✅ "诶,这霜也太厚了吧!"

### 对白推动剧情

每句话要么:
- 展现痛点:"又要开会,杯里的白开水一点味都没有"
- 引入产品:"试试这个,先说好,头一口不是甜的"
- 表现效果:"诶,真回甘了,一点都不腻"
- 促成行动:"我也囤几罐,办公室常备"

### 用感官细节代替形容词

- ❌ "口感醇厚,回甘持久"
- ✅ "头一口有点苦,咽下去三秒,满嘴回甘"
- 效果只写口感、心情、习惯的变化,不写身体变化;台词里的数字只能来自商品信息或检测报告。

### 控制节奏

- 痛点阶段:短句,急促,表现焦虑
- 尝试阶段:正常语速,好奇
- 效果阶段:感叹句,惊喜
- 行动号召:肯定句,真诚推荐

## 场景描述

### 环境写实

不是摄影棚,是真实生活场景:

- 办公室:电脑屏幕、咖啡杯、文件
- 家里:沙发、猫爬架、宠物碗
- 户外:公园长椅、健身器材

### 动作细节

用动作展现情绪和状态:

- 痛点:盯着屏幕叹气、推开甜饮料、皱眉
- 尝试:撕开包装、闻香、小口尝试
- 效果:眼睛一亮、满意点头、拍照分享

### 产品特写时机

在关键转折点给产品特写:
- 递过来的瞬间(包装正面)
- 冲泡时刻(白霜/颜色变化)
- 效果展现后(再次特写,强化记忆)

## 情感节奏

场景种草的情感曲线:

```
困扰/焦虑(低点) → 尝试(平缓上升) → 效果惊喜(高点) → 满足/想分享(稳定高位)
```

控制每个阶段的时长:
- 困扰:快速建立(3-5秒)
- 尝试:自然过渡(3-4秒)
- 效果:重点展现(5-6秒)
- 行动号召:简短有力(2-3秒)

# 输出格式

只输出一个合法的 JSON 对象,不要有任何前后说明文字:

```json
{
  "title": "视频标题",
  "logline": "一句话故事梗概",
  "content": "完整 Markdown 剧本(注意:content 字段内的换行符必须转义为 \\n,双引号必须转义为 \\\")",
  "characters": ["人物1", "人物2"],
  "locations": ["场景1", "场景2"],
  "props": ["道具1", "道具2"]
}
```

**重要**: `content` 字段是一个 JSON 字符串,必须正确转义:
- 换行符用 `\n` 表示
- 双引号用 `\"` 表示
- 反斜杠用 `\\` 表示

自检清单:

1. 痛点场景具体真实,有画面感;
2. 产品植入自然,不是硬广;
3. 人物对白口语化,不念广告词;
4. 情感曲线清晰:困扰 → 惊喜 → 满足;
5. 创意大纲的钩子、核心信息、行动号召已落实;
6. Markdown 格式完整,包含人物、场景、道具、创作说明。
