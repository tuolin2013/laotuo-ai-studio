# 对比测评类创作方法论

## 核心公式

**对比钩子 → 维度选择 → 逐项对比 → 结论呈现**

## 三种对比形式

### 1. 横向品牌对比

**适用**:同类产品竞争激烈的品类

**对比维度**(选 2-3 个):
- 价格:同规格价格对比
- 成分:配料表逐项对比
- 含量:有效成分含量数据
- 包装:规格、便携性
- 口感/效果:主观体验(需真实)

**注意**:
- 不点名同行品牌,用 A/B/C 或"普通 XX"代替
- 只陈述客观差异,不贬低
- 数据必须真实可查

### 2. 使用前后对比

**适用**:效果可见的产品(护肤、清洁、宠物保健)

**对比呈现**:
- 同框分屏:左边使用前,右边使用后
- 时间线:Day 1 → Day 7 → Day 30
- 局部特写:问题区域的变化

**可信度保障**:
- 光线条件一致
- 拍摄角度一致
- 标注时间(非立即见效的产品)
- 说明个体差异

### 3. 成分拆解测评

**适用**:功能性产品、保健品、宠物营养品

**拆解层次**:
- 配料表对比:逐项列出
- 关键成分含量:数据可视化
- 添加剂对比:有无、多少
- 性价比计算:每克/每份有效成分的价格

## 公平性设计

对比测评最怕**不公平**,会引发反感和信任危机。

### 对比公平原则

1. **同等条件**
   - 同规格、同价位段
   - 同样的测试方法
   - 同样的环境条件

2. **客观陈述**
   - ❌ "某品牌垃圾"
   - ✅ "A 品牌黄酮 2.3%,我们的 6.8%,差距 3 倍"

3. **承认优势**
   - 如果对比对象某方面更好,客观陈述
   - 强调自家产品的差异化优势,而非全面碾压

4. **个体差异声明**
   - 主观体验类(口感、效果)要声明"个人体验"
   - 效果类要标注"因人而异"

### 避免的行为

- 选择劣质对比对象衬托自己
- 故意选不利条件测试对手
- 只对比自己占优的维度
- 夸大差异("天壤之别")

## 数据可视化

对比测评的灵魂是**让差异可见**。

### 视觉化手段

1. **并排陈列**
   - 两个/三个产品同框
   - 包装、颜色、质地对比

2. **数据标注**
   - 在画面上叠加数据(百分比、克数、价格)
   - 用箭头、高亮、放大突出关键差异

3. **图表呈现**
   - 柱状图:含量对比
   - 表格:多维度对比
   - 分屏:前后对比

4. **倍数呈现**
   - "3 倍""2 倍"比抽象数字更有冲击力
   - 用视觉面积体现倍数(3 个杯子 vs 1 个杯子)

### 数据来源标注

所有数据必须标注来源:
- "根据配料表"
- "第三方检测报告"
- "官方旗舰店标价"
- "使用 30 天个人体验"

## 对白设计

### 测评者人设

对比测评需要**中立、专业、可信**的测评者:

- 身份:产品体验师、成分党、专业铲屎官
- 态度:客观,不偏袒
- 语气:平静陈述,用数据说话

### 对白原则

1. **先说对比维度**
   - "今天对比三个维度:价格、黄酮含量、口感"

2. **逐项陈述差异**
   - "价格:A 品牌 128 元 50g,我们 98 元 50g"
   - "黄酮:A 品牌 2.3%,我们 6.8%,差了 3 倍"

3. **给出选择建议**
   - "如果你看重性价比和含量,我们更合适"
   - "如果你偏好某某口味,A 品牌也不错"

### 避免的表达

- "秒杀""吊打""碾压"等攻击性词汇
- "垃圾""假货""智商税"等贬损
- 暗示对手违法违规的表述

## 情感节奏

对比测评的情感曲线:

```
疑惑(用户选择困难) → 对比展开(逐渐清晰) → 差异呈现(恍然大悟) → 明确选择(决策确定)
```

不需要激动或煽动,而是**理性、清晰、值得信赖**。

# 合规

对比测评类对合规要求**极其严格**:

1. **不得点名贬低同行**
   - 不出现竞品品牌名
   - 不使用贬损性词汇

2. **数据必须真实**
   - 可查证、可验证
   - 标注数据来源

3. **客观陈述差异**
   - 不夸大、不捏造
   - 承认对手优势(如有)

4. **个体差异声明**
   - 主观体验要声明
   - 效果类要标注"因人而异"

5. **避免绝对化用语**
   - "最好""第一""唯一"等

违反以上任一条,都可能引发**不正当竞争**投诉。

# 输出格式

只输出一个合法的 JSON 对象,不要有任何前后说明文字:

```json
{
  "title": "视频标题",
  "logline": "一句话故事梗概",
  "content": "完整 Markdown 剧本(注意:content 字段内的换行符必须转义为 \\n,双引号必须转义为 \\\")",
  "characters": ["测评者"],
  "locations": ["测评场景"],
  "props": ["产品A", "产品B", "配料表", "检测报告"]
}
```

**重要**: `content` 字段是一个 JSON 字符串,必须正确转义:
- 换行符用 `\n` 表示
- 双引号用 `\"` 表示
- 反斜杠用 `\\` 表示

自检清单:

1. 对比维度明确,2-3 个足够;
2. 对比条件公平,同规格同价位;
3. 数据真实,标注来源;
4. 客观陈述,无贬损用语;
5. 差异可视化,一目了然;
6. 给出选择建议,不强迫;
7. 严格遵守合规要求;
8. 创意大纲的钩子、核心信息已落实。
