# 产品展示类创作方法论

## 核心公式

**强感官钩子 → 外观展示 → 细节特写 → 使用过程 → 效果呈现**

## ASMR 声音设计

产品展示类的灵魂是**物理声音**,不是人说话。

### 高价值声音素材

按类目选择:

**茶类/冲调品**:
- 撕袋声(嘶啦、清脆)
- 倾倒声(干茶摩擦、颗粒流动)
- 注水声(沸水冲击、气泡翻腾)
- 搅拌声(勺子碰壁、液体旋转)

**宠物食品**:
- 撕袋声(主人视角)
- 倾倒声(颗粒落入碗中)
- 咀嚼声(宠物进食,清晰但不恶心)
- 舔舐声(满足感)

**固体食品**:
- 开盖声(密封破开)
- 切开声(刀切/手撕)
- 咀嚼声(酥脆/软糯)

### 声音分层

一个镜头可以有多层声音:
- 主声音:当前动作的物理音效
- 环境音:空间感(厨房、客厅)
- 细节音:质感体现(包装纸摩擦、液体流动)

### 声音与画面同步

声音必须与画面动作**精确同步**:
- ❌ "画面:撕开包装;声音:注水声"
- ✅ "画面:手指捏住封口;声音:撕袋前的轻微拉扯声 → 画面:用力撕开;声音:清脆的嘶啦声"

## 视觉分层展示

### 四层递进

1. **整体外观**(3-4秒)
   - 包装正面、品牌、设计感
   - 中近景,完整展示

2. **开启瞬间**(2-3秒)
   - 撕开/开盖的动作特写
   - 微距,捕捉关键瞬间

3. **产品细节**(4-5秒)
   - 质地、颜色、形态
   - 超微距,展现独特之处(白霜、颗粒、纹理)

4. **使用与效果**(4-5秒)
   - 冲泡/喂食/食用过程
   - 最终呈现(茶汤、宠物满足表情、切面)

### 运镜节奏

- 外观:缓慢推进,稳定
- 开启:固定机位,不晃动
- 细节:极慢推进或固定,让观众看清
- 使用:跟随动作,自然流畅

## 对白设计

产品展示类**少说话,多展示**。

### 三种对白策略

**策略 1:纯 ASMR,无对白**
- 只有物理声音和环境音
- 适合:高品质产品、强视觉冲击、成熟用户

**策略 2:关键提示**
- 只在转折点说 1-2 句
- 例如:"看这个白霜"(引导注意力),"闻到没"(调动感官)
- 语气轻柔,不打断 ASMR

**策略 3:产品解说**
- 边展示边介绍关键卖点
- 语速平缓,不抢声音
- 例如:"张家界莓茶,叶面自然白霜,总黄酮的数字就印在检测报告上"

选择策略的依据:
- 产品复杂度:简单产品选策略1,复杂产品选策略3
- 平台特性:抖音偏爱 ASMR,淘宝逛逛需要解说
- 用户认知:认知成熟选策略1,需要教育选策略3

## 微距与特写

### 什么值得微距

**必拍特写**:
- 产品独特之处(白霜、颗粒大小、纹理)
- 品质证明(厚实包装、完整形态、色泽)
- 使用瞬间(冲泡变化、宠物反应、切面质地)

### 微距要点

1. **光线充足**:自然光或柔和顶光
2. **背景简洁**:纯色或浅景深虚化
3. **焦点准确**:对准最想展示的部分
4. **时长充足**:每个微距至少 2 秒,让观众看清

## 情感节奏

产品展示的情感曲线:

```
好奇(钩子) → 惊艳(细节) → 向往(使用) → 想拥有(效果)
```

不需要强烈的情感波动,而是**持续的品质感和满足感**。

# 输出格式

只输出一个合法的 JSON 对象,不要有任何前后说明文字:

```json
{
  "title": "视频标题",
  "logline": "一句话故事梗概",
  "content": "完整 Markdown 剧本(注意:content 字段内的换行符必须转义为 \\n,双引号必须转义为 \\\")",
  "characters": [],
  "locations": ["场景1"],
  "props": ["产品", "道具1", "道具2"]
}
```

**重要**: `content` 字段是一个 JSON 字符串,必须正确转义:
- 换行符用 `\n` 表示
- 双引号用 `\"` 表示
- 反斜杠用 `\\` 表示

自检清单:

1. 声音设计清晰,物理音效与画面同步;
2. 视觉分层完整:外观 → 开启 → 细节 → 使用 → 效果;
3. 微距时刻精准,展现产品独特之处;
4. 对白策略明确,不抢声音;
5. 创意大纲的钩子、核心信息已落实;
6. Markdown 格式完整,包含声音设计、创作说明。
