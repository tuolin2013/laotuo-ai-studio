# 动效设计法则（带货动效广告版）

本指南把下面几个开源动效 Skill 里可以量化的规则整理成一份，按本项目的动效引擎（`app/engine/motion/`）落地。
只引用规则和数值，没有照搬原文：

| heygen-com/hyperframes（motion-doctrine、cut-the-curve 等内部 Skill） | Apache-2.0 | 动势衔接转场（矢量定律）、穿梭缩放参数、模糊上限、单片转场种类上限 |

动效引擎已经自动执行第 2~8 节的全部规则；写动效方案时，你只需要决定**结构、文案、素材、拍数、镜头和转场**。

---

## 1. 节拍：每一刀都落在拍子上

- 1 拍 = 60 / BPM 秒。分镜长度一律是整数拍，所以剪辑点天然落在拍点上。
- BPM 对应情绪：72~88 沉稳、高级（茶、滋补、高端礼盒）；90~110 从容、利落（大多数带货）；112~128 兴奋、促销感（大促、上新）。
- 先排节拍表，再写画面：开场钩子 2~5 拍；之后每个分镜 4~8 拍；信息多的屏（卖点清单、长图滚动）8~14 拍；收尾 6~10 拍。
- **起势点**：钩子之后的第一个剪辑点。配乐在这里才进鼓点和贝斯，并配一次「起势 → 重击」音效。全片只有这一次，所以钩子后面要接全片最重要的画面（商品主视觉）。
- 画面不要静止超过 1 秒：内容落定后，背景光斑、图片的缓推缓拉、按钮扫光会继续动。

## 2. 缓动：没有「线性」的入场和退场

| 用途 | 曲线 | 手感 |
|---|---|---|
| 入场 | cubic-bezier(0.16, 1, 0.3, 1) | 带着速度进来，轻轻落定 |
| 退场 | cubic-bezier(0.7, 0, 0.84, 0) | 慢起快走 |
| 画面内移动 | cubic-bezier(0.65, 0, 0.35, 1) | 匀加速再匀减速 |
| 动势衔接转场 | power4.in → 剪辑点 → power4.out | 两侧速度连续 |
| 主角落地 | cubic-bezier(0.55, 0, 0.2, 1.12) | 约 4% 的轻微过冲 |

- 线性只用于持续漂移、旋转和颗粒。
- 弹簧阻尼比 ζ = c / (2√(k·m)) 不低于 0.72，否则显得廉价。引擎预设：利落 320/30、默认 170/26、厚重 120/24。
- 回弹（ζ≈0.4）**整支片子只用一次**，留给收尾的价格 / 活动胶囊。禁止 bounce、elastic 这类缓动。

## 3. 时长

- 单个元素入场 0.5~0.9 秒，退场是入场的 50%~75%（0.24~0.3 秒）。
- 错峰：逐字 30~45 毫秒、清单逐条 200 毫秒，但**一组元素的总错峰不超过 0.5 秒**。
- 跟随元素滞后主体 100~300 毫秒入场（对勾晚于卖点卡片 120 毫秒、副标题晚于主标题收尾前 300 毫秒）。
- 剪辑点之前的退场 + 之后的入场合计约 0.6~0.8 秒。
- 阅读停留：中文每秒最多 8 个字（Netflix 简体中文字幕上限是 9 字 / 秒），再加 0.6 秒入场。副标题按一半字数算。收尾行动至少 3 秒，开场钩子不超过 3 秒（黄金 3 秒）。
- **文字在被阅读时绝不移动**：落定之后到退场之前，文字完全静止，至少停 0.5 秒。

## 4. 文字动效

- 主标题逐字「遮罩上升」：每个字从自己行框下方 105% 的位置升起，不透明度在前 15% 的进度里到位。不做慢吞吞的整体淡入。
- 副标题整块上浮淡入，与主标题收尾重叠 0.3 秒。
- 每屏只强调一个词（主题强调色渐变），强调词必须是主标题原文的一部分。
- 数字用计数滚动（DIN 风格数字字体），落定瞬间「顶」一下（1 → 1.05 → 1）并配一记低音。百分比下方配进度条，副标题里有「标准 ≥24%」这样的基准时会画出基准刻度。
- 字数上限：主标题 ≤16 字，副标题 ≤28 字，卖点条目 ≤14 字，按钮 ≤8 字，数字 / 胶囊 ≤12 字。
- 断行优先在空格处：「霜多叶嫩 看得见」会排成两行。所以想控制断行就在短语之间加空格。

## 5. 镜头与层次

- 三层运动：主体（商品、标题）> 跟随（副标题、对勾、细线）> 环境（背景光斑、图片缓推）。环境层的运动量不超过主体的 20%。
- 图片卡片默认缓推 1 → 1.06（钩子背景 1.08）。相邻分镜交替「缓推 / 缓拉」让节奏有变化；**同一个镜头里不要先推再拉来回折返**。
- 横移只用于宽幅图片。静止（still）只用于需要仔细看的检测报告、配料表。
- 图集里相邻卡片漂移速度不同（视差 1.0 / 0.6）。
- 主图按原比例完整放进卡片，不裁掉主图上的文字。详情页长图放进手机外框里匀加速再匀减速地滚动；界面截图放进浏览器外框。

## 6. 转场

| 转场 | 做法 | 适合 |
|---|---|---|
| 卡点硬切 `cut` | 剪辑点直接切，下一屏入场动作已经在动 | 节奏紧的连续卖点 |
| 动势推移 `push` | 上一屏加速向上（横屏向左）离开 12% 画面，下一屏从同方向接住速度；快速位移时加运动模糊 | 默认转场 |
| 穿梭缩放 `zoom` | 上一屏放大 1→1.2 并模糊，下一屏从 0.82 放大到 1 | 钩子之后进入主视觉、进入长图 |
| 色块擦除 `wipe` | 强调色色块推过画面，在剪辑点盖满 | 段落切换（如从「为什么」到「怎么选」），全片最多一次 |

- 矢量定律：下一屏入场的方向、轴向与上一屏退场一致（推移永远同一个方向，缩放两侧都是放大）。
- 一支片子最多用 3 种转场。**不用交叉淡化**（叠化）：画面互相叠在一起，永远显得廉价。
- 模糊上限：文字 10 像素、整屏 18~20 像素；运动模糊绝不跨越剪辑点。

## 7. 质感

- 发布会暗场：近黑底 + 青、蓝、紫三团缓慢漂移的柔光（周期 20~28 秒），白字 + 青→蓝强调渐变。
- 其余主题沿用主图 / 详情页的 5 大美学流派色板，让动效广告与同一项目的主图、详情页是一个视觉系统。
- 暗角：画面 56% 半径以内完全透明，往外压到约 22% 的黑。胶片颗粒不透明度约 4.5%，每两帧换一次。
- 卡片：圆角约为短边的 5.5%，柔和投影，毛玻璃半透明底 + 1~2 像素细描边。
- 编码：H.264 CRF 17、yuv420p、BT.709，30 fps。

## 8. 声音（全部本机合成，没有版权问题）

- 配乐按 BPM 与主题调式生成（新中式 / 山野用五声调式）。钩子段只有铺底和弹拨（留白），起势点进鼓点、贝斯、琶音，最后两小节撤掉鼓点只留和弦长音。底鼓触发侧链压缩，铺底随节拍「呼吸」。
- 音效与画面事件对齐：转场呼啸声的峰值落在剪辑点上；起势音效恰好在起势点结束，接一记重击；卖点逐条落定的提示音按音阶逐级升高；价格胶囊弹出配一声「啵」；按钮扫光配一声轻微的闪光音。
- 连续的运动（漂移、缓推）不配音效；音效宁少勿多，不用网络梗音效。
- 整片响度 -14 LUFS，真峰值 ≤ -1.5 dBTP。

## 9. 带货动效的结构

一条 15~30 秒的带货动效，推荐结构：

1. **钩子大字** `hook`（2~5 拍，≤3 秒）：痛点、反常识或强利益点，一句话、≤10 个字最好。可用一张有氛围的图做背景。
2. **商品主视觉** `hero`（5~8 拍）：起势点上的主角镜头，主图 + 商品名 / 一句定位。
3. **证据** `stat`（4~6 拍）：一个可查证的数字（检测值、含量、规格），副标题写出处或标准。没有可靠数字就不要这一屏。
4. **卖点清单** `features`（6~10 拍）：2~4 条，每条一件事，≤14 字。
5. **图集** `gallery`（4~8 拍）：2~6 张主图 / 首帧，展示多角度、多场景。
6. **长图滚动** `showcase`（8~14 拍）：详情页长图在手机里滚动，或在手机里播放一段分镜视频。
7. **收尾行动** `cta`（6~10 拍，≥3 秒）：一句行动号召 + 价格 / 活动胶囊 + 按钮。

不必每种都用：短片 4~6 屏就够，同一类型可以出现两次（例如两屏卖点清单），但不要连续两屏用同一个版式。

## 10. 自检清单（渲染后自动执行）

渲染完成后，系统自动生成联系表（每个分镜内容落定后 0.3 秒各取一帧）并逐项检查：

1. 剪辑点全部落在节拍上（误差不超过半帧）。
2. 第一个分镜是钩子，且不超过 3 秒。
3. 最后一个分镜是收尾行动，且至少 3 秒。
4. 每屏文字都有足够的阅读时间（每秒 8 个字 + 入场）。
5. 文字落定后至少停 0.5 秒再退场。
6. 文字都在安全区内（竖屏中间约 75% 宽度、避开顶部搜索栏与底部文案区）。
7. 同一屏的文字互不遮挡。
8. 转场种类不超过 3 种。
9. 第 0 帧不是黑屏。
10. 没有画面突跳或单帧闪烁（逐帧比对，剪辑点与转场除外）。
11. 整片响度统一到 -14 LUFS 左右。

## 11. 反模式

- 线性缓动、只有不透明度变化的淡入淡出、所有元素同时入场或时长完全一样。
- 叠化转场、没有画面元素推动的「通用擦除」、整屏推出画面外。
- 同一个镜头里先推再拉来回折返；转场方向左右来回变。
- 回弹、橡皮筋缓动，卡通式过冲，彩虹渐变，满屏粒子，不止一个发光元素，拿表情符号当图标。
- 文字被阅读时还在动，或者一闪而过；一屏多个视觉焦点；文字贴边。
- 第 0 帧是黑屏，开场 3 秒没有信息。
- 音效每个动作都配、迟到的重击、不止一次起势。
- 广告法违禁词与类目违禁词（见类目配置 `forbidden_words`）。
