## 可用素材（按剧本分镜顺序）

- `actual_seconds`：素材实际时长；`planned_seconds`：剧本计划时长（H3 最短生成约 5.2 秒，所以短镜头的素材往往比计划长）。
- `spoken_line`：这个镜头里人物实际说出口的台词；`estimated_speech_seconds`：按中速口播估算的台词时长。
- `sound_spans`：程序用音量检测找到的有声时间段 `[开始秒, 结束秒]`（台词 + 环境音 / 动作音效）。H3 的台词经常不是从第 0 秒开始，**剪辑点以这些时间段为准**，不要按计划时长硬切。

# 剪辑规则

1. **黄金前 3 秒**：`shot_index = 1` 的钩子镜头必须放在第一位、必须启用；台词说完立刻切走，不留空镜，钩子镜头成片时长尽量 ≤ 3 秒。
2. **掐头**：H3 片段开头约 0.2~0.4 秒是静止的锁定首帧，台词前常有一段等待。入点取第一个 `sound_spans` 开始前约 0.3~0.5 秒（但不早于 0）；没有声音段落的镜头入点取 0.2~0.4 秒，切掉静止段让画面一上来就在动。钩子镜头同样剪掉台词前的空等。
3. **去尾**：出点取最后一个 `sound_spans` 结束后 0.3~0.6 秒，给人物留一个反应或动作收尾；没有台词的镜头按动作完成点出，单镜不超过 4 秒，除非是产品特写或喂食 / 冲泡等过程展示。
4. **绝不剪断台词**：有 `spoken_line` 的镜头，入点不晚于第一个声音段落开头，出点不早于最后一个声音段落结尾，`source_out - source_in` 必须 ≥ `estimated_speech_seconds + 0.3`，且不超过 `actual_seconds`。
5. **顺序**：默认沿用剧本顺序；只有在明显能让卖点更连贯时才调整中间镜头的顺序。钩子永远第一，行动号召（`call_to_action`）永远最后。
6. **时长控制**：成片总时长尽量落在剧本目标时长与平台推荐时长之间。确实超长时，可以把重复表达同一卖点的镜头设为 `enabled: false`，但钩子和行动号召镜头不能停用。
7. **转场**（`transition_out` 表示切到下一个镜头的方式，最后一个镜头填 `cut`）：
   - 默认 `cut` 硬切，带货视频靠硬切保持节奏；
   - 场景或时间明显变化时用 `fade` 叠化（0.3~0.5 秒）；
   - 产品揭晓、前后对比的瞬间可用 `fadewhite` 闪白（0.2~0.3 秒）；`fadeblack` 闪黑只用于情绪转折；
   - 全片非硬切转场不超过 2 个。转场会借用出点之后的素材，所以使用转场的镜头出点要比素材结尾早至少 0.3 秒。
8. **卖点花字**（`headline`，显示在画面上方，整段镜头常驻）：
   - 每条 ≤ 14 个字，优先用数字、规格、产地、原料、口感等具体信息，例如「0.4g 小片 · 鸡肝粉风味」；
   - 只给最关键的 3~5 个镜头加花字，其余留空字符串，避免满屏是字；
   - 不要重复同一镜头里人物已经说出的台词，花字是对台词的补充；
   - 行动号召镜头用一句明确的下单引导，例如「点击下方链接 马上拥有」。
9. **原声音量**（`volume`，0~2，1 为原始音量）：有台词的镜头保持 1.0；纯环境音镜头可设 0.8~1.0，后期会叠加背景音乐。
10. **台词字幕不用你写**：程序会把 `spoken_line` 原样做成台词字幕，你只负责剪辑点和花字。
11. **合规**：花字与标题不得出现类目 `forbidden_words` 中的任何词，不写功效、疗效、医疗用语，不用「最」「第一」「100%」等绝对化用语。

# 输出格式

只输出一个 JSON 对象，不要输出解释文字或代码块标记。`clips` 按成片顺序排列，必须包含素材列表里的每个 `shot_index` 恰好一次（停用的镜头也要列出，`enabled` 填 false）：

{
  "title": "成片标题（≤20 字，用作草稿名与导出文件名）",
  "edit_summary": "一句话说明剪辑思路：节奏、总时长、转场与花字安排",
  "clips": [
    {
      "shot_index": 1,
      "enabled": true,
      "source_in": 0.0,
      "source_out": 2.8,
      "transition_out": "cut",
      "transition_seconds": 0.3,
      "volume": 1.0,
      "headline": "卖点花字，可为空字符串"
    }
  ]
}
