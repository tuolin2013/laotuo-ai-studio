# 🏭 老庹 AI 电商内容工厂 · 免 Key 在线体验

老庹 AI 工作室（Laotuo AI Studio）出品的电商 AIGC 内容工作台。这里是**公共在线演示**：不用填任何 API Key，
所有生成都走本机演示模式（本机绘制预览图、合成演示视频与提示音），不调用付费接口。

## 打开就能试

页面打开时会自动为你准备一份自己的示例项目（张家界莓茶示例主图 4 张、详情页 4 屏），别人看不到。

1. 切到 **✨ 动效广告** 选项卡；
2. 点 **🎬 AI 编排动效方案**：动效导演按节拍编排分镜（钩子 → 卖点 → 收尾），每一刀都落在节拍上；
3. 点 **⚡ 快速预览（540P）**：在这台服务器上逐帧渲染画面、合成配乐与音效，并给出联系表和 14 项自检报告。

主图、详情页、带货视频、配音几个选项卡也都可以走完整流程（演示模式）。

## 公共演示的限制

- 单条动效广告最长 30 秒；同一时间只渲染 1 条，排队的最多 5 条，满了请过一两分钟再试；
- 项目超过 1 小时没有操作会自动清理，渲染好的成片请及时下载；
- 不提供 API 配置、历史项目与音色库（这些在本机部署时才有）；
- 没有登录鉴权：请不要上传隐私或机密图片。

## 本机部署 / 接入真实接口

源码与完整文档：<https://github.com/tuolin2013/laotuo-ai-studio>
